# 6.3 填充和步幅（Padding and Stride）

在 6.2 节中，我们推导出了最基础的卷积输出尺寸公式：
$$\mathbf{输出尺寸} = (n_h - k_h + 1) \times (n_w - k_w + 1)$$

这个公式暴露了传统卷积的两个致命局限：
1. **边界信息丢失与尺寸坍塌（Border Shrinkage）**：输出尺寸必然小于输入尺寸。如果一张 $240 \times 240$ 的图像经过 10 层 $5 \times 5$ 卷积，尺寸会衰减到 $200 \times 200$；若网络加深到几十层，图像很快就会缩减至 $1 \times 1$ 而无法继续深入。此外，图像角落的像素只被卷积核扫描了 1 次，而中心像素被扫描了 $k \times k$ 次，边界信息被严重边缘化。
2. **算力冗余与分辨率下降过慢**：对于千万像素的高清大图，每次只移动 1 个像素不仅计算开销极大，且相邻滑窗之间存在极高的冗余信息。

为了精准调控特征图的空间几何演化，卷积神经网络引入了两个最为核心的超参数调控杠杆：**填充（Padding）** 与 **步幅（Stride）**。

---

## 一、填充（Padding）：守住边界与空间保真

为了防止特征图层层缩水，最直接有效的办法是在输入图像的四周**垫上一圈额外的元素**（通常填充数值为 $0$，称为**零填充 Zero-Padding**）。

![[attachments/slide_217_padding_intro.png]]

### 1. 填充后的输出尺寸公式

假设我们在输入图像的高度方向总共填充 $p_h$ 行（顶部垫 $\lfloor p_h/2 \rfloor$，底部垫 $\lceil p_h/2 \rceil$），在宽度方向总共填充 $p_w$ 列（左侧垫 $\lfloor p_w/2 \rfloor$，右侧垫 $\lceil p_w/2 \rceil$）。

![[attachments/slide_217_padding_formula.png]]

此时等效于输入尺寸变成了 $(n_h + p_h) \times (n_w + p_w)$，代入基础公式：

$$\mathbf{输出高} = n_h - k_h + p_h + 1, \qquad \mathbf{输出宽} = n_w - k_w + p_w + 1$$

> [!caution] PyTorch 中的 `padding` 参数约定（极其容易踩坑！）
> 在 PyTorch 的 `nn.Conv2d(..., padding=p)` 中：
> * 参数 `p` 代表的是**单边填充量（Per-side Padding）**！
> * 当你传入 `padding=1` 时，PyTorch 会在**上、下、左、右各垫 1 行/列**！
> * 这意味着总填充量为：$p_h = 2 \times 1 = 2$，$p_w = 2 \times 1 = 2$！
> * 如果传入元组 `padding=(p_top_bottom, p_left_right)`，总高度填充量为 $2 \times p_{\text{tb}}$，总宽度填充量为 $2 \times p_{\text{lr}}$。

---

### 2. “等径卷积（Same Convolution）”黄金法则：$p = k - 1$

在绝大多数现代卷积神经网络（如 ResNet、VGGNet）的特征提取层中，架构师都希望**卷积前后的空间分辨率严格保持一致**（即输出尺寸等于输入尺寸：$n_h - k_h + p_h + 1 = n_h$）。

要让输出高与输入高完全相等，必须满足：
$$-k_h + p_h + 1 = 0 \implies \mathbf{p_h = k_h - 1}$$

由于两边对称填充（$p_{\text{side}} = p_h / 2$），单侧填充量为：
$$\mathbf{单边填充量} = \frac{k - 1}{2}$$

![[attachments/slide_217_padding_example.png]]

> [!important] 为什么深度学习中的卷积核几乎全是奇数？（3×3, 5×5, 7×7）
> 1. **整数对称填充**：如果 $k$ 是奇数，那么 $k - 1$ 必然是偶数，单侧填充量 $(k - 1) / 2$ 必然是一个**完美的整数**！上下左右可以填充完全相同数量的 0，维持图像几何对称。若 $k$ 是偶数，则必须上下不对称填充（如一边填 1 另一边填 2），破坏对称性。
> 2. **唯一的中心锚点（Center Pixel）**：奇数核拥有唯一的几何几何中心像素（例如 $3 \times 3$ 核的中心在第 2 行第 2 列），这使得输出特征图的每一个点 $Y[i, j]$ 可以毫无歧义地精准对应输入图像的锚点 $X[i, j]$。

## 二、步幅（Stride）：大幅降采样与算力提速

在前面的卷积计算中，滑窗每次仅向右或向下滑动 1 个像素（即默认步幅 $s = 1$）。

但在处理高分辨率图像时，我们希望快速压缩特征图尺寸、减少计算量并加速扩大后层感受野。此时卷积窗口可以**跨步滑动（跳着走）**。

![[attachments/slide_217_stride_intro.png]]

### 1. 步幅几何过程

若水平步幅为 $s_w = 2$，垂直步幅为 $s_h = 2$：
* 卷积核在第一行计算完第 1 个输出后，向右直接跳过 2 个像素计算第 2 个输出；
* 一行扫描完毕后，向下跳过 2 个像素开始下一行的扫描。

![[attachments/slide_217_stride_example.png]]

---

### 2. 包含填充与步幅的“终极输出尺寸公式”

假设输入高宽为 $n_h, n_w$，卷积核为 $k_h, k_w$，总填充量为 $p_h, p_w$，步幅为 $s_h, s_w$：

![[attachments/slide_217_stride_formula.png]]

$$\mathbf{输出高} = \left\lfloor \frac{n_h - k_h + p_h + s_h}{s_h} \right\rfloor = \left\lfloor \frac{n_h - k_h + p_h}{s_h} \right\rfloor + 1$$
$$\mathbf{输出宽} = \left\lfloor \frac{n_w - k_w + p_w + s_w}{s_w} \right\rfloor = \left\lfloor \frac{n_w - k_w + p_w}{s_w} \right\rfloor + 1$$

* 符号 $\lfloor \cdot \rfloor$ 表示向下取整（Floor）。

#### 严格数学推导：
设沿高度方向一共能滑动 $m$ 步（索引步数 $i = 0, 1, 2, \dots, m$）。
第 $i$ 次放置时，窗口覆盖的输入最高索引为 $i \cdot s_h + k_h - 1$。
为保证窗口不超出填充后的边界总长度 $n_h + p_h - 1$，必须满足：
$$i \cdot s_h + k_h - 1 \le n_h + p_h - 1 \implies i \cdot s_h \le n_h - k_h + p_h$$
$$i \le \frac{n_h - k_h + p_h}{s_h}$$
由于 $i$ 必须是整数，最大的合法索引步数为 $\left\lfloor \frac{n_h - k_h + p_h}{s_h} \right\rfloor$。
从步数 0 到最大步数，总共放置次数（即输出高度）为：
$$\text{输出高度} = \left\lfloor \frac{n_h - k_h + p_h}{s_h} \right\rfloor + 1 = \left\lfloor \frac{n_h - k_h + p_h + s_h}{s_h} \right\rfloor$$

---

### 3. 两种极其重要的工程简化特例

1. **若设置等径填充 $p = k - 1$**：
   $$\text{输出} = \left\lfloor \frac{n + (k - 1) - k + s}{s} \right\rfloor = \left\lfloor \frac{n + s - 1}{s} \right\rfloor$$
2. **若输入尺寸 $n$ 刚好能被步幅 $s$ 整除**：
   $$\mathbf{输出尺寸} = \frac{n}{s}$$
   例如：输入 $224 \times 224$，使用 $3 \times 3$ 卷积、填充 $p=1$、步幅 $s=2$，输出尺寸**直接腰斩**为 $112 \times 112$！

---

## 三、PyTorch 代码实战验证

我们通过官方教材的测试函数 `comp_conv2d`，验证上述公式的精确性：

```python
import torch
from torch import nn

def comp_conv2d(conv2d, X):
    """辅助函数：自动添加批量和通道维度 (1, 1)，计算后展平回 2D 形状返回"""
    X = X.reshape((1, 1) + X.shape)
    Y = conv2d(X)
    return Y.reshape(Y.shape[2:])

# 输入一张 8x8 的测试图像
X = torch.rand(size=(8, 8))
```

### 实验 1：单边填充 1（$3 \times 3$ 核实现空间保真）
```python
# 每边填充 1 行/列，总填充 ph = 2, pw = 2
conv2d = nn.Conv2d(1, 1, kernel_size=3, padding=1)
print("实验 1 输出形状:", comp_conv2d(conv2d, X).shape)
# 输出: torch.Size([8, 8])
```
* **算式验证**：$8 - 3 + (2 \times 1) + 1 = 8$。完美保真！

---

### 实验 2：非对称核与非对称填充
```python
# 卷积核 (5, 3)，高度单侧填 2，宽度单侧填 1
conv2d = nn.Conv2d(1, 1, kernel_size=(5, 3), padding=(2, 1))
print("实验 2 输出形状:", comp_conv2d(conv2d, X).shape)
# 输出: torch.Size([8, 8])
```
* **算式验证**：
  * 高度：$8 - 5 + (2 \times 2) + 1 = 8$
  * 宽度：$8 - 3 + (2 \times 1) + 1 = 8$

---

### 实验 3：步幅为 2（尺寸腰斩）
```python
conv2d = nn.Conv2d(1, 1, kernel_size=3, padding=1, stride=2)
print("实验 3 输出形状:", comp_conv2d(conv2d, X).shape)
# 输出: torch.Size([4, 4])
```
* **算式验证**：$\lfloor (8 - 3 + 2 + 2) / 2 \rfloor = \lfloor 9 / 2 \rfloor = 4$。尺寸直接变为输入的一半！

---

### 实验 4：复合复杂超参数（非对称核 + 非对称填充 + 非对称步幅）
```python
conv2d = nn.Conv2d(1, 1, kernel_size=(3, 5), padding=(0, 1), stride=(3, 4))
print("实验 4 输出形状:", comp_conv2d(conv2d, X).shape)
# 输出: torch.Size([2, 2])
```
* **算式验证**：
  * 高度：$\lfloor (8 - 3 + 0 + 3) / 3 \rfloor = \lfloor 8 / 3 \rfloor = \mathbf{2}$
  * 宽度：$\lfloor (8 - 5 + (2 \times 1) + 4) / 4 \rfloor = \lfloor 9 / 4 \rfloor = \mathbf{2}$
  * 代码运行结果与公式推导 100% 吻合！

## 四、本节小结

![[attachments/slide_217_summary.png]]

1. **填充（Padding）的核心使命**：防止深层网络边缘信息严重流失和特征图过早萎缩。通常选取 $p = (k - 1) / 2$ 使得输入与输出高宽完全一致。
2. **步幅（Stride）的核心使命**：快速降采样，成倍压缩空间维度，降低后续层浮点运算量（FLOPs），并成倍拉大感受野。
3. **架构常规惯例**：现代网络一般采用统一对称超参数（$p_h = p_w, s_h = s_w$），且绝大多数卷积层采用奇数尺寸核（$3 \times 3$ 或 $1 \times 1$）。

### 练习 1：对于本节中的最后一个示例，计算其输出形状，以查看它是否与实验结果一致。

**解答与手算步骤**：
示例配置：
* 输入尺寸：$n_h = 8, n_w = 8$
* 卷积核：$k_h = 3, k_w = 5$
* 单边填充：`padding=(0, 1)` $\implies p_h = 0 \times 2 = 0, \quad p_w = 1 \times 2 = 2$
* 步幅：`stride=(3, 4)` $\implies s_h = 3, \quad s_w = 4$

代入终极计算公式：
$$\text{输出高} = \left\lfloor \frac{n_h - k_h + p_h + s_h}{s_h} \right\rfloor = \left\lfloor \frac{8 - 3 + 0 + 3}{3} \right\rfloor = \left\lfloor \frac{8}{3} \right\rfloor = \mathbf{2}$$
$$\text{输出宽} = \left\lfloor \frac{n_w - k_w + p_w + s_w}{s_w} \right\rfloor = \left\lfloor \frac{8 - 5 + 2 + 4}{4} \right\rfloor = \left\lfloor \frac{9}{4} \right\rfloor = \mathbf{2}$$

手算结果为 $(2, 2)$，与 PyTorch 实验输出 `torch.Size([2, 2])` 完全一致。

### 练习 3：对于音频信号，步幅 2 说明什么？

**解答**：
音频是一维的时域连续波形采样信号（例如 44.1 kHz 采样率）。当在一维音频时域卷积中设置步幅 $s = 2$ 时：
1. **时间降采样（Decimation / Downsampling）**：输出时间步长直接缩减为原来的一半（相当于时间维度上的二倍降采样）；
2. **频率上限折叠（奈奎斯特准则 Nyquist Limit）**：根据奈奎斯特采样定理，时间分辨率减半意味着该层所能表达的最大无失真频率上限减半，高频信息被转化为低频或抽象包络；
3. **时间感受野倍增**：下一层卷积核每向前迈进 1 个时间步，等价于在原始音频上跨越了 2 个原始采样点的时间跨度（更高效地捕捉长音拍和音节节奏）。

### 练习 4：步幅大于 1 的计算优势是什么？

**解答**：
步幅 $s > 1$ 是卷积网络在深层降低计算开销的核心手段：
1. **空间分辨率二次方锐减**：当 $s = 2$ 时，输出特征图的高和宽各自减半，整张特征图的元素总数暴跌为原来的 **$\frac{1}{4}$**（$25\%$）；
2. **计算量（FLOPs）暴跌**：后续卷积层的滑窗次数减少为四分之一，浮点运算量直接削减近 $75\%$；
3. **显存占用锐减**：中间激活张量（Activation Map）所占显存大幅下降，允许在相同 GPU 显存限制下使用更大的批处理大小（Batch Size）或构建更深的网络；
4. **感受野以指数级爆炸扩张**：包含步幅 $s$ 时，感受野递归公式变为：
   $$RF_{l} = RF_{l-1} + (k_l - 1) \cdot \prod_{i=1}^{l-1} s_i$$
   累乘项 $\prod s_i$ 会使高层神经元的感受野呈指数级放大，迅速建立全图全局语义。
