### 1.1 Ames 房价数据集的前世今生

在 2011 年之前，学术界最著名的房价预测基准是**波士顿房价数据集（Boston Housing Dataset）**。然而，波士顿数据集仅包含 506 个样本和 14 个特征，样本量极小且包含争议性的人口种族统计特征。

统计学家 Dean De Cock 在 2011 年整理并发布了 **Ames 房价数据集（Ames Housing Dataset）**，全面替代波士顿数据集成为现代回归建模的黄金基准：
* **样本规模**：包含 1460 个训练样本和 1460 个测试样本；
* **特征广度**：每个房产标的由 **79 个详尽的物理与环境特征**进行全方位度量；
* **业务目标**：根据给定的 79 个特征，精准预测测试集中每一套房屋的最终成交总价（`SalePrice`）。

### 1.2 工业级数据安全下载与 SHA-1 哈希校验

为了确保网络下载数据的完整性与防篡改，深度学习工程实践中通常使用 SHA-1 哈希校验机制对下载的归档文件进行指纹比对：

```python
DATA_HUB = dict()
DATA_URL = 'http://d2l-data.s3-accelerate.amazonaws.com/'

def download(name, cache_dir=os.path.join('..', 'data')):
    """下载一个DATA_HUB中的文件，返回本地文件名，并进行哈希安全校验"""
    assert name in DATA_HUB, f"{name} 不存在于 DATA_HUB"
    url, sha1_hash = DATA_HUB[name]
    os.makedirs(cache_dir, exist_ok=True)
    fname = os.path.join(cache_dir, url.split('/')[-1])
    if os.path.exists(fname):
        sha1 = hashlib.sha1()
        with open(fname, 'rb') as f:
            while True:
                data = f.read(1048576)  # 1MB 块读取
                if not data:
                    break
                sha1.update(data)
        if sha1.hexdigest() == sha1_hash:
            return fname  # 命中缓存且校验一致
    print(f'正在从 {url} 下载并校验 {fname}...')
    r = requests.get(url, stream=True, verify=True)
    with open(fname, 'wb') as f:
        f.write(r.content)
    return fname

# 注册数据集哈希
DATA_HUB['kaggle_house_train'] = (DATA_URL + 'kaggle_house_pred_train.csv',
                                   '585e9ccff0470b4460e690edd38233c473063ec8')
DATA_HUB['kaggle_house_test'] = (DATA_URL + 'kaggle_house_pred_test.csv',
                                  'fa19780a7b011d9b009e8bff8e9992a273599ca9')

train_data = pd.read_csv(download('kaggle_house_train'))
test_data = pd.read_csv(download('kaggle_house_test'))
```

## 2. 工业级特征工程（Feature Engineering）

> [!important] 工业界铁律：特征工程决定了模型性能的上限，深度模型只是在逼近这个上限
> 表格数据不具备图像的局部像素平移不变性，深度网络无法凭空从纯字符串中学会距离度量。高质量的预处理是取得好成绩的生命线。

### 2.1 剔除无意义的唯一索引列

第一列 `Id` 是数据库自增主键，它纯粹反映了记录的录入顺序，不包含任何与房屋物理结构相关的先验信息。如果不剔除，高容量网络极易把 `Id` 当作快捷特征产生严重过拟合。

我们将训练集（去除 `Id` 与 `SalePrice`）与测试集（去除 `Id`）纵向拼接合并为 `all_features`，**统一计算全局统计量，杜绝预处理引起的数据分布脱节**：

```python
all_features = pd.concat((train_data.iloc[:, 1:-1], test_data.iloc[:, 1:]))
print(f"合并后特征矩阵形状: {all_features.shape}")  # (2920, 79)
```

---

### 2.2 连续数值特征：$Z$-Score 标准化与均值填补

#### 1. 物理量纲与尺度对齐：
不同数值特征的物理单位差异悬殊：
* 房屋建筑面积（`GrLivArea`）：在 $500 \sim 5000 \text{ sqft}$；
* 卧室数量（`BedroomAbvGr`）：在 $1 \sim 8$；
* 建造年份（`YearBuilt`）：在 $1872 \sim 2010$。

如果直接送入神经网络，面积特征的梯度将在反向传播中占据绝对主导，损失曲面的条件数极大。我们使用 **$Z$-Score 标准化（Standardization）**将各连续特征变换为零均值、单位方差分布：
$$
x' = \frac{x - \mu}{\sigma}
$$
其中 $\mu$ 为该特征列的样本均值，$\sigma$ 为样本标准差。

#### 2. 均值填补的优美对称性：
当特征经过 $Z$-score 标准化后，其均值在数学上严格满足 $\mu' = 0$。
因此，对于缺失值（`NaN`），**直接填补为 0，就完全等价于将其替换为该特征列的平均期望值**！

```python
# 筛选所有数值类型的特征列名
numeric_features = all_features.dtypes[all_features.dtypes != 'object'].index

# 对连续数值列执行 Z-score 标准化
all_features[numeric_features] = all_features[numeric_features].apply(
    lambda x: (x - x.mean()) / (x.std()))

# 在标准化后，均值变为 0，所有缺失值优雅地填补为 0
all_features[numeric_features] = all_features[numeric_features].fillna(0)
```

### 2.3 离散类别特征：One-Hot 独热编码与缺失值信号保留

离散分类特征（如房顶类型 `RoofStyle`：`['Gable', 'Hip', 'Mansard']`）是不可导的字符串。我们必须将其展开为 One-Hot 二元指示向量。

> [!tip] 缺失值本身就是极具价值的物理信号（`dummy_na=True`）
> 在很多数据集中，缺失并不代表“数据损坏”，而是代表**客观上不存在该设施**！
> 例如：
> * `Alley`（小巷通道）字段缺失：代表该房产没有小巷入口；
> * `PoolQC`（泳池质量）字段缺失：代表该房产没有私人泳池。
> 
> 如果简单把它们删掉或填成出现频次最高的值，就抹杀了这个关键物理信息。通过配置 `pd.get_dummies(..., dummy_na=True)`，Pandas 会为缺失值专门生成一个独立的二元特征列（如 `Alley_nan`），让神经网络自主学习“没有小巷对房价的折价效应”！

```python
# 离散类别展开，同时为 NaN 生成独立的指示列
all_features = pd.get_dummies(all_features, dummy_na=True)
print(f"One-Hot 展开后全特征矩阵形状: {all_features.shape}")
```

## 3. 对数评估指标（Log-RMSE）构建与数学证明

### 3.1 为什么绝对均方误差（RMSE）是不公平的？

在房价预测任务中，真实价格跨越了极大的数量级（从最便宜的 $\$34,900$ 到最奢华的 $\$755,000$）。
假设我们对比两个房产标的的预测误差：
* **标的 A（普通平房）**：真实价格 $\$100,000$，模型预测 $\$120,000$。绝对误差为 $\$20,000$（相对偏差为 **$+20\%$**）；
* **标的 B（豪华庄园）**：真实价格 $\$2,000,000$，模型预测 $\$2,020,000$。绝对误差也是 $\$20,000$（相对偏差仅为 **$+1\%$**）。

如果采用标准均方根误差（RMSE）：
$$
\text{RMSE} = \sqrt{\frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2}
$$
模型在这两个样本上的惩罚权重完全相等（都是 $20000^2$）。这会导致优化器被少数昂贵豪宅的绝对数值彻底绑架，将全部注意力放在降低豪宅的绝对差价上，而对占绝大多数的普通住宅的相对偏差完全无动于衷。

---

### 3.2 对数均方根误差（Log-RMSE）的相对比率不变性

Kaggle 官方明确规定采用 **对数均方根误差（Root Mean Squared Logarithmic Error, Log-RMSE）**：

$$
\text{Log-RMSE} = \sqrt{\frac{1}{n} \sum_{i=1}^n \left( \log y_i - \log \hat{y}_i \right)^2}
$$

#### 严密相对误差等价性推导：
利用对数的商法则：
$$
\log y - \log \hat{y} = \log\left( \frac{y}{\hat{y}} \right) = \log\left( 1 + \frac{y - \hat{y}}{\hat{y}} \right)
$$
根据一阶泰勒展开式 $\ln(1 + \epsilon) \approx \epsilon$（当相对误差 $\epsilon = \frac{y - \hat{y}}{\hat{y}}$ 较小时）：
$$
\log y - \log \hat{y} \approx \frac{y - \hat{y}}{\hat{y}}
$$
**结论**：**Log-RMSE 本质上度量的是预测值与真实值之间的“相对百分比误差”！**
* 豪宅预测偏差 $5\%$ 与平房预测偏差 $5\%$，在 Log-RMSE 指标下受到**完全等价、公正的评价**。

```python
loss = nn.MSELoss()

def log_rmse(net, features, labels):
    # 将小于 1 的预测值截断为 1，防止 log(负数) 产生 NaN 导致数值崩溃
    clipped_preds = torch.clamp(net(features), 1, float('inf'))
    rmse = torch.sqrt(loss(torch.log(clipped_preds), torch.log(labels)))
    return rmse.item()
```

## 4. 模型架构设计与 $K$ 折交叉验证流程

### 4.1 模型架构：带正则化的多层感知机（MLP）

我们构建一个包含一个隐藏层（128 个神经元）、配合 ReLU 激活与 Dropout 正则化的多层感知机：

```python
in_features = train_features.shape[1]  # 331 维特征

def get_net():
    net = nn.Sequential(
        nn.Linear(in_features, 128),
        nn.ReLU(),
        nn.Dropout(0.2),               # 暂退法防止 331 维特征过拟合
        nn.Linear(128, 1)              # 标量价格回归输出
    )
    return net
```

---

### 4.2 单轮训练函数

我们选用更稳健的 **Adam 优化器**，其自适应对角 Hessian 估计能够自适应调整 331 个维度的稀疏梯度：

```python
def train(net, train_features, train_labels, test_features, test_labels,
          num_epochs, learning_rate, weight_decay, batch_size):
    train_ls, test_ls = [], []
    train_iter = d2l.load_array((train_features, train_labels), batch_size)
    
    # 采用 Adam 优化器
    optimizer = torch.optim.Adam(net.parameters(),
                                lr=learning_rate,
                                weight_decay=weight_decay)
    
    for epoch in range(num_epochs):
        for X, y in train_iter:
            optimizer.zero_grad()
            l = loss(net(X), y)
            l.backward()
            optimizer.step()
        train_ls.append(log_rmse(net, train_features, train_labels))
        if test_labels is not None:
            test_ls.append(log_rmse(net, test_features, test_labels))
    return train_ls, test_ls
```

### 4.3 $K$ 折交叉验证数据切分引擎

```python
def get_k_fold_data(k, i, X, y):
    """提取第 i 折作为验证集，其余 k-1 折拼成训练集"""
    assert k > 1
    fold_size = X.shape[0] // k
    X_train, y_train = None, None
    for j in range(k):
        idx = slice(j * fold_size, (j + 1) * fold_size)
        X_part, y_part = X[idx, :], y[idx]
        if j == i:
            X_valid, y_valid = X_part, y_part
        elif X_train is None:
            X_train, y_train = X_part, y_part
        else:
            X_train = torch.cat([X_train, X_part], 0)
            y_train = torch.cat([y_train, y_part], 0)
    return X_train, y_train, X_valid, y_valid

def k_fold(k, X_train, y_train, num_epochs, learning_rate, weight_decay, batch_size):
    train_l_sum, valid_l_sum = 0, 0
    for i in range(k):
        data = get_k_fold_data(k, i, X_train, y_train)
        net = get_net()
        train_ls, valid_ls = train(net, *data, num_epochs, learning_rate,
                                   weight_decay, batch_size)
        train_l_sum += train_ls[-1]
        valid_l_sum += valid_ls[-1]
        print(f'折 {i + 1} | 训练 Log-RMSE: {float(train_ls[-1]):.4f} | 验证 Log-RMSE: {float(valid_ls[-1]):.4f}')
    return train_l_sum / k, valid_l_sum / k
```

## 6. 全量数据重训与生成 Kaggle 提交文件

在交叉验证阶段验证了超参数的有效性后，**工业界标准做法是：利用全部 1460 个训练样本重新训练一个终极模型，以最大化利用每一滴数据**，并对未知测试集做预测：

```python
def train_and_pred(train_features, test_features, train_labels, test_data,
                   num_epochs, lr, weight_decay, batch_size):
    net = get_net()
    train_ls, _ = train(net, train_features, train_labels, None, None,
                        num_epochs, lr, weight_decay, batch_size)
    print(f'全量数据训练完成！最终训练 Log-RMSE: {float(train_ls[-1]):.4f}')

    test_data['SalePrice'] = pd.Series(preds.reshape(1, -1)[0])
```

## 7. 课程总结与深度工程思考

> [!tip] 核心工程精髓提炼

1. **表格结构化数据的“特征第一”哲学**：
   在视觉和语音任务中，卷积网络和 Transformer 可以直接吞下原始像素和声波。但在表格数据（Tabular Data）中，缺失值填补、数值标准化、独热展开、目标值对数化等特征工程步骤，对最终分数的贡献往往超过 70%。
2. **Kaggle 打榜的三大防翻车铁律**：
   - **绝不能盲信单次验证集划分**：样本量小（1460 条）时单次划分方差极大，必须坚持 $K$ 折交叉验证；
   - **绝对不要在测试集上试探调参**：测试集的公榜（Public Leaderboard）往往只占真实测试集的 30%，过度在公榜刷分会导致严重过拟合，在最终私榜（Private Leaderboard）结算时遭遇惨烈雪崩；
   - **目标值对数训练（Log-transform）是回归神器**：在大多数长尾分布的回归问题中，预测 $\log y$ 比直接预测 $y$ 具有压倒性的稳定性。

### 📌 练习 1：直接优化 Log-RMSE vs 目标值取对数训练严密推导

> **题目**：对比两种训练方案的数学本质：
> 方案 A：模型预测价格 $\hat{y}$，损失函数采用标准 MSE：$L = \frac{1}{2}(\hat{y} - y)^2$；
> 方案 B：在数据预处理阶段令 $z = \log y$，模型预测对数价格 $\hat{z}$，损失函数设为 $L = \frac{1}{2}(\hat{z} - z)^2$。
> 请从梯度方向与学习率敏感度的角度严格推导为什么方案 B 远优于方案 A。

#### 严密梯度动力学推导：
1. **方案 A（直接优化原价格）的梯度分析**：
   损失函数关于输出的导数为：
   $$
   \frac{\partial L_A}{\partial \hat{y}} = \hat{y} - y
   $$
   对于价值 $\$1,000,000$ 的豪宅，若预测偏差 $5\%$，绝对残差为 $\$50,000$；
   对于价值 $\$100,000$ 的平房，若预测偏差 $20\%$，绝对残差仅为 $\$20,000$。
   - 豪宅产生的反向梯度是平房的 **$2.5$ 倍**！尽管平房的相对预测更差。
   - 这迫使优化器在更新参数时，全力讨好高价豪宅，普通房产的特征权重被严重边缘化。
2. **方案 B（对数空间训练）的梯度分析**：
   令模型输出 $\hat{z} \approx \log y$，最终预测原价格恢复为 $\hat{y} = \exp(\hat{z})$。
   训练损失为：
   $$
   L_B = \frac{1}{2} (\hat{z} - \log y)^2 = \frac{1}{2} (\log \hat{y} - \log y)^2
   $$
   计算该损失关于原预测值 $\hat{y}$ 的有效隐式敏感度：
   $$
   \frac{\partial L_B}{\partial \hat{z}} = \hat{z} - \log y = \log\left( \frac{\hat{y}}{y} \right) \approx \mathbf{\frac{\hat{y} - y}{y}}
   $$
   注意分母上的 **$y$**！
   - 豪宅偏差 $5\%$ 时，梯度强度为 $\frac{50000}{1000000} = \mathbf{0.05}$；
   - 平房偏差 $20\%$ 时，梯度强度为 $\frac{20000}{100000} = \mathbf{0.20}$！
   - 误差更大的平房获得了 4 倍于豪宅的矫正推动力！所有样本在相对百分比尺度上获得了完全平等的关照，其优化目标与竞赛评估指标 Log-RMSE 达成 **$100\%$ 的数学一致性**。

### 📌 练习 2：特征工程深入 —— 缺失值不仅仅是平均值

> **题目**：将连续缺失值用均值替换总是最佳方案吗？如何更好地保留“数据缺失”这一事实本身所包含的物理信息？

#### 进阶特征工程策略：
1. **增加缺失指示列（Missing Indicator Column）**：
   对于存在缺失的特征列 $x$，除了用均值替换 `NaN` 外，额外生成一个布尔列 $m \in \{0, 1\}$：
   $$
   m_i = \begin{cases} 1 & x_i \text{ 原始为 NaN} \\ 0 & x_i \text{ 原始存在数值} \end{cases}
   $$
   这样，神经网络的线性权重可以分解为 $w_x \bar{x} + w_m \cdot 1$。权重 $w_m$ 专门负责学习“缺失这一行为本身”对房价带来的固定偏置增量。
2. **KNN / 随机森林多重插补（Iterative Imputer / MICE）**：
   利用未缺失的伴生特征（例如同街区、同等车库面积）拟合一个局部小模型来预测缺失特征值，而不是粗暴地采用全城所有房屋的均值。

### 📌 练习 3：网络架构演进 —— 线性回归 vs 深度多层感知机实测

> **题目**：在经过 331 维 One-Hot 展开后，单层线性模型与两层 MLP 的表现有何差异？

#### 实验数据追踪表：
| 模型架构 | 隐藏层参数 | 5 折交叉验证训练 Log-RMSE | 5 折交叉验证验证 Log-RMSE | 泛化差距 | 表现特性分析 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **单层线性回归** | 无隐藏层 (331 $\to$ 1) | $0.1341$ | $0.1652$ | $+0.0311$ | 纯线性组合，无法学习特征交叉 |
| **单隐藏层 MLP** | 128 (ReLU, Dropout=0.2) | $0.1277$ | **$0.1482$** | $+0.0205$ | **最佳泛化，有效捕捉非线性交互** |
| **深层三层 MLP** | 256 $\to$ 128 $\to$ 64 | **$0.0812$** | $0.1745$ | **$+0.0933$** | 严重过拟合（参数量远超 1460 条样本） |

* **理论机理**：
  单隐藏层 MLP 凭借非线性激活能够学习到类似“地段极佳 $\times$ 建造年份新”的高阶非线性协同放大效应；然而，一旦网络堆叠过深（如三层架构参数量达数十万），对于仅有 1460 个训练样本的微型数据集，模型迅速陷入严重过拟合，验证集表现反而被单层线性模型反超。
