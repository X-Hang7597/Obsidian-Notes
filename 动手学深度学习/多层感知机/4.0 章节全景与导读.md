# 第4章 多层感知机（Multilayer Perceptrons, MLP）

在本章中，我们将第一次介绍真正的**深度网络**。

最简单的深度网络称为**多层感知机（MLP）**。多层感知机由多层神经元组成，每一层与它的上一层相连，从中接收输入；同时每一层也与它的下一层相连，影响当前的神经元。

当我们训练容量较大的模型时，我们面临着**过拟合（Overfitting）**的风险。因此，本章将从基本的概念开始讲起，包括过拟合、欠拟合和模型选择。为了解决这些问题，本章将介绍**权重衰减（Weight Decay）**和**暂退法（Dropout）**等经典正则化技术。我们还将讨论**数值稳定性（Numerical Stability）**和**参数初始化（Parameter Initialization）**相关的关键问题，这些问题是成功训练深度网络的核心基石。

在本章的最后，我们将把所介绍的内容应用到一个真实的工业级案例：**Kaggle 比赛：加州/爱荷华房价预测**。

## 核心认知跨越：为什么需要多层感知机？

第 3 章我们研究的线性模型形式为 $\mathbf{y} = \mathbf{X}\mathbf{W} + \mathbf{b}$。
在线性模型中，每个特征对输出的影响都是相互独立的，无法捕捉特征之间的协同与非线性关联。

如果简单地堆叠多个线性层：
$$
\mathbf{y} = (\mathbf{X} \mathbf{W}_1 + \mathbf{b}_1) \mathbf{W}_2 + \mathbf{b}_2 = \mathbf{X} (\mathbf{W}_1 \mathbf{W}_2) + (\mathbf{b}_1 \mathbf{W}_2 + \mathbf{b}_2) = \mathbf{X} \mathbf{W}' + \mathbf{b}'
$$
**仿射变换的仿射变换依然是仿射变换！** 叠加 100 层纯线性层，其表达能力与单层没有任何区别。

**破局之道**：
在每两个线性层之间插入**非线性激活函数（Non-linear Activation Function）$\sigma(\cdot)$**：
$$
\mathbf{H} = \sigma(\mathbf{X} \mathbf{W}_1 + \mathbf{b}_1), \quad \mathbf{O} = \mathbf{H} \mathbf{W}_2 + \mathbf{b}_2
$$
非线性激活函数的引入，赋予了神经网络弯曲、折叠高维空间的能力，这也是**通用近似定理（Universal Approximation Theorem）**成立的前提——只要有足够的隐藏单元，单隐藏层多层感知机就能够以任意精度逼近任何紧凑子集上的连续函数。
