# 线性回归的从零开始实现

在了解线性回归的关键思想之后，我们可以开始通过代码来动手实现线性回归了。
在这一节中，**我们将从零开始实现整个方法，包括数据流水线、模型、损失函数和小批量随机梯度下降优化器**。
虽然现代的深度学习框架几乎可以自动化地进行所有这些工作，但从零开始实现可以确保我们真正知道自己在做什么。
同时，了解更细致的工作原理将方便我们自定义模型、自定义层或自定义损失函数。
在这一节中，我们将只使用张量和自动求导。
在之后的章节中，我们会充分利用深度学习框架的优势，介绍更简洁的实现方式。

```python
%matplotlib inline
import random
import torch
from d2l import torch as d2l
```

## 生成数据集

为了简单起见，我们将**根据带有噪声的线性模型构造一个人造数据集。**
我们的任务是使用这个有限样本的数据集来恢复这个模型的参数。
我们将使用低维数据，这样可以很容易地将其可视化。
在下面的代码中，我们生成一个包含1000个样本的数据集，
每个样本包含从标准正态分布中采样的2个特征。
我们的合成数据集是一个矩阵$\mathbf{X}\in \mathbb{R}^{1000 \times 2}$。

我们使用线性模型参数 $\mathbf{w} = [2, -3.4]^\top$、$b = 4.2$ 和噪声项 $\epsilon$ 生成数据集及其标签：

$$\mathbf{y}= \mathbf{X} \mathbf{w} + b + \mathbf\epsilon.$$

$\epsilon$可以视为模型预测和标签时的潜在观测误差。
在这里我们认为标准假设成立，即$\epsilon$服从均值为0的正态分布。
为了简化问题，我们将标准差设为0.01。
下面的代码生成合成数据集。

```python
def synthetic_data(w, b, num_examples):  #@save
    """生成y=Xw+b+噪声"""
    X = torch.normal(0, 1, (num_examples, len(w)))
    y = torch.matmul(X, w) + b
    y += torch.normal(0, 0.01, y.shape)
    return X, y.reshape((-1, 1))
```

```python
true_w = torch.tensor([2, -3.4])
true_b = 4.2
features, labels = synthetic_data(true_w, true_b, 1000)
```

注意，**`features` 中的每一行都包含一个二维数据样本，`labels` 中的每一行都包含一维标签值（一个标量）**。

```python
print('features:', features[0],'\nlabel:', labels[0])
```

> ```

## 读取数据集

回想一下，训练模型时要对数据集进行遍历，每次抽取一小批量样本，并使用它们来更新我们的模型。
由于这个过程是训练机器学习算法的基础，所以有必要定义一个函数，
该函数能打乱数据集中的样本并以小批量方式获取数据。

在下面的代码中，我们**定义一个 `data_iter` 函数，该函数接收批量大小、特征矩阵和标签向量作为输入，生成大小为 `batch_size` 的小批量**。
每个小批量包含一组特征和标签。

```python
def data_iter(batch_size, features, labels):
    num_examples = len(features)
    indices = list(range(num_examples))
    # 这些样本是随机读取的，没有特定的顺序
    random.shuffle(indices)
    for i in range(0, num_examples, batch_size):
        batch_indices = torch.tensor(
            indices[i: min(i + batch_size, num_examples)])
        yield features[batch_indices], labels[batch_indices]
```

通常，我们利用GPU并行运算的优势，处理合理大小的“小批量”。
每个样本都可以并行地进行模型计算，且每个样本损失函数的梯度也可以被并行计算。
GPU可以在处理几百个样本时，所花费的时间不比处理一个样本时多太多。

我们直观感受一下小批量运算：读取第一个小批量数据样本并打印。
每个批量的特征维度显示批量大小和输入特征数。
同样的，批量的标签形状与`batch_size`相等。

```python
batch_size = 10

for X, y in data_iter(batch_size, features, labels):
    print(X, '\n', y)
    break
```

它可以处理存储在文件中的数据和数据流提供的数据。

## 初始化模型参数

**在我们开始用小批量随机梯度下降优化我们的模型参数之前**，
**我们需要先有一些参数**。
在下面的代码中，我们通过从均值为0、标准差为0.01的正态分布中采样随机数来初始化权重，
并将偏置初始化为0。

```python
w = torch.normal(0, 0.01, size=(2,1), requires_grad=True)
b = torch.zeros(1, requires_grad=True)
```

在初始化参数之后，我们的任务是更新这些参数，直到这些参数足够拟合我们的数据。
每次更新都需要计算损失函数关于模型参数的梯度。
有了这个梯度，我们就可以向减小损失的方向更新每个参数。
因为手动计算梯度很枯燥而且容易出错，所以没有人会手动计算梯度。
我们使用 自动求导中引入的自动微分来计算梯度。

## 定义模型

接下来，我们必须**定义模型，将模型的输入和参数同模型的输出关联起来。**
回想一下，要计算线性模型的输出，
我们只需计算输入特征$\mathbf{X}$和模型权重$\mathbf{w}$的矩阵-向量乘法后加上偏置$b$。
注意，上面的$\mathbf{Xw}$是一个向量，而$b$是一个标量。
回想一下 广播机制中描述的广播机制：
当我们用一个向量加一个标量时，标量会被加到向量的每个分量上。

```python
def linreg(X, w, b):  #@save
    """线性回归模型"""
    return torch.matmul(X, w) + b
```

## 定义损失函数

因为需要计算损失函数的梯度，所以我们应该先定义损失函数。
这里我们使用 [[3.1 线性回归|3.1 节 (线性回归)]]中描述的平方损失函数。
在实现中，我们需要将真实值`y`的形状转换为和预测值`y_hat`的形状相同。

```python
def squared_loss(y_hat, y):  #@save
    """均方损失"""
    return (y_hat - y.reshape(y_hat.shape)) ** 2 / 2
```

## 定义优化算法

正如我们在 [[3.1 线性回归|3.1 节 (线性回归)]]中讨论的，线性回归有解析解。
尽管线性回归有解析解，但本书中的其他模型却没有。
这里我们介绍小批量随机梯度下降。

在每一步中，使用从数据集中随机抽取的一个小批量，然后根据参数计算损失的梯度。
接下来，朝着减少损失的方向更新我们的参数。
下面的函数实现小批量随机梯度下降更新。
该函数接受模型参数集合、学习速率和批量大小作为输入。每
一步更新的大小由学习速率`lr`决定。
因为我们计算的损失是一个批量样本的总和，所以我们用批量大小（`batch_size`）
来规范化步长，这样步长大小就不会取决于我们对批量大小的选择。

```python
def sgd(params, lr, batch_size):  #@save
    """小批量随机梯度下降"""
    with torch.no_grad():
        for param in params:
            param -= lr * param.grad / batch_size
            param.grad.zero_()
```

## 训练

现在我们已经准备好了模型训练所有需要的要素，可以实现主要的**训练过程**部分了。
理解这段代码至关重要，因为从事深度学习后，
相同的训练过程几乎一遍又一遍地出现。
在每次迭代中，我们读取一小批量训练样本，并通过我们的模型来获得一组预测。
计算完损失后，我们开始反向传播，存储每个参数的梯度。
最后，我们调用优化算法`sgd`来更新模型参数。

概括一下，我们将执行以下循环：

* 初始化参数
* 重复以下训练，直到完成
    * 计算梯度$\mathbf{g} \leftarrow \partial_{(\mathbf{w},b)} \frac{1}{|\mathcal{B}|} \sum_{i \in \mathcal{B}} l(\mathbf{x}^{(i)}, y^{(i)}, \mathbf{w}, b)$
    * 更新参数$(\mathbf{w}, b) \leftarrow (\mathbf{w}, b) - \eta \mathbf{g}$

在每个*迭代周期*（epoch）中，我们使用`data_iter`函数遍历整个数据集，
并将训练数据集中所有样本都使用一次（假设样本数能够被批量大小整除）。
这里的迭代周期个数`num_epochs`和学习率`lr`都是超参数，分别设为3和0.03。
设置超参数很棘手，需要通过反复试验进行调整。
我们现在忽略这些细节，以后会在 优化算法中详细介绍。

```python
lr = 0.03
num_epochs = 3
net = linreg
loss = squared_loss
```

```python
for epoch in range(num_epochs):
    for X, y in data_iter(batch_size, features, labels):
        l = loss(net(X, w, b), y)  # X和y的小批量损失
        # 因为l形状是(batch_size,1)，而不是一个标量。l中的所有元素被加到一起，
        # 并以此计算关于[w,b]的梯度
        l.sum().backward()
        sgd([w, b], lr, batch_size)  # 使用参数的梯度更新参数
    with torch.no_grad():
        train_l = loss(net(features, w, b), labels)
        print(f'epoch {epoch + 1}, loss {float(train_l.mean()):f}')
```

> [!example]- 运行输出
> ```text
> epoch 1, loss 0.042790
> epoch 2, loss 0.000162
> 
> epoch 3, loss 0.000051
> ```

因为我们使用的是自己合成的数据集，所以我们知道真正的参数是什么。
因此，我们可以通过**比较真实参数和通过训练学到的参数来评估训练的成功程度**。
事实上，真实参数和通过训练学到的参数确实非常接近。

```python
print(f'w的估计误差: {true_w - w.reshape(true_w.shape)}')
print(f'b的估计误差: {true_b - b}')
```

> [!example]- 运行输出
> ```text
> w的估计误差: tensor([-1.3804e-04,  5.7936e-05], grad_fn=<SubBackward0>)
> b的估计误差: tensor([0.0006], grad_fn=<RsubBackward1>)
> ```

注意，我们不应该想当然地认为我们能够完美地求解参数。
在机器学习中，我们通常不太关心恢复真正的参数，而更关心如何高度准确预测参数。
幸运的是，即使是在复杂的优化问题上，随机梯度下降通常也能找到非常好的解。
其中一个原因是，在深度网络中存在许多参数组合能够实现高度精确的预测。

## 练习与深度题解

### 📌 练习 1：如果我们将权重初始化为零，会发生什么？算法仍然有效吗？

> [!note] 核心结论：算法仍然【完全有效】
> 在**线性回归**中，全零初始化不会使模型瘫痪，SGD 依然能够完全收敛到全局最优解。

#### 一、预测值与梯度表现
   - 当 $\mathbf{w} = \mathbf{0}, b = 0$ 时，第一个批次的前向预测值全部为零：$\hat{y} = \mathbf{X}\mathbf{0} + 0 = 0$。
   - 此时残差（误差）为 $e = \hat{y} - y = 0 - y = -y \neq 0$。
   - 梯度为 $\nabla_{\mathbf{w}} l = (\hat{y} - y)\mathbf{x} = -y\mathbf{x} \neq \mathbf{0}$。
   - 只要输入特征 $\mathbf{x}$ 和真实标签 $y$ 不全为零，梯度就不为零。在第一步更新时，权重立即离开零点：$\mathbf{w} \leftarrow \mathbf{0} - \eta (-y\mathbf{x}) = \eta y \mathbf{x} \neq \mathbf{0}$。
#### 二、凸优化性质保障
   - 线性回归的目标函数是严格的单极小值凸函数（大铁碗形状）。从零点出发和从其他随机点出发，最终都会顺着梯度滚落到唯一的碗底。
#### 三、与多层神经网络（MLP）的本质区别
   - 多层神经网络有隐藏层。若同一层的多个隐藏神经元权重全部初始化为零，由于**对称性（Symmetry）**，所有神经元接收相同输入、产生相同激活、回传相同梯度，导致所有神经元永远步调一致，网络退化为单个神经元（对称性无法打破）。
   - 但线性回归**只有 1 个输出神经元，不存在多神经元对称性问题**，因此全零初始化完全可行。

### 📌 练习 2：假设试图为电压和电流的关系建立一个模型。自动微分可以用来学习模型的参数吗？

> [!note] 核心结论：完全可以，且这正是科学计算（AI for Science / 物理信息模型）的标准范式。

#### 一、概念对齐与物理映射
   - 欧姆定律：$U = I \cdot R + b_{\text{offset}}$
   - 线性模型：$y = w \cdot x + b$
   - 自变量 $x \leftrightarrow$ 测得电流 $I$；真实标签 $y \leftrightarrow$ 测得电压 $U$；模型权重 $w \leftrightarrow$ 未知物理电阻 $R$；偏置 $b \leftrightarrow$ 电压表零点漂移误差。
#### 二、极简代码实现
   ```python
   R = torch.tensor([1.0], requires_grad=True)  # 待学物理参数，初始瞎猜 1.0
   U_hat = I * R                                 # 理论前向计算
   loss = ((U_hat - U) ** 2).mean()              # 测量均方误差
   loss.backward()                               # 自动反向求导
   with torch.no_grad():
       R -= lr * R.grad                          # 优化更新
       R.grad.zero_()
   ```
#### 三、自动微分的降维打击
   - 对于线性电阻，传统最小二乘法也能算；
   - 但对于**非线性元件**（如二极管伏安特性 $I = I_s (e^{U/V_T} - 1)$），传统手工求偏导极其繁琐。自动微分允许我们只写前向物理定律代码，由引擎通过计算图自动应用链式法则求解未知物理常数的梯度，省去全部人工微积分推导。

### 📌 练习 3：能基于普朗克定律使用光谱能量密度来确定物体的温度吗？

> [!note] 核心结论：理论完全可行，工程上正是红外测温仪、热成像与天体物理测量恒星温度的通用做法。

#### 一、建模方式
   - 普朗克黑体辐射公式：$B(\lambda, T) = \frac{2hc^2}{\lambda^5} \frac{1}{\exp\left(\frac{hc}{\lambda k_B T}\right) - 1}$
   - 输入特征：波长序列 $\lambda$；真实标签：测量光谱能量密度 $B$；学习参数：物体温度 $T$（标量，`requires_grad=True`）。
   - 优化目标：$\text{Loss} = \frac{1}{m}\sum (\hat{B}_i - B_i)^2$，通过梯度下降更新温度 $T$。
#### 二、凸性与全局收敛保证
   - 对任意波长 $\lambda$，辐射强度对温度具有严格单调性（$\frac{\partial B}{\partial T} > 0$ 恒成立，越热辐射越强）。因此损失函数关于温度是单峰碗状曲线，梯度下降绝不会陷入局部极值陷阱，100% 收敛到真实温度。
#### 三、必须注意的数值计算陷阱
   - 普朗克常数 $h \approx 10^{-34}$，光速 $c \approx 3 \times 10^8$，波长 $\lambda \sim 10^{-7}$，直接以标准国际单位输入 PyTorch `float32` 会发生极严重的**浮点数下溢/溢出（瞬间引发 NaN 或 Inf）**。
   - 工程中必须进行**无量纲化（归一化）**，或两边取对数（Log-Planck）后再进行优化。

### 📌 练习 4：计算二阶导数时可能会遇到什么问题？这些问题可以如何解决？

> [!note] 核心结论：二阶导数（牛顿法）具备曲率信息无需选学习率，但面临“显存爆炸、求逆耗时、鞍点陷阱”三大难题。

#### 一、三大致命问题
   - **显存爆炸（空间复杂度 $O(d^2)$）**：二阶 Hessian 矩阵大小为 $d \times d$。仅 10 万参数的模型，单单存下该矩阵就需要约 $40\text{ GB}$ 显存。
   - **计算耗时爆炸（时间复杂度 $O(d^3)$）**：牛顿法更新需计算逆矩阵 $\mathbf{H}^{-1}$，对于大参数量网络计算完全不可行。
   - **鞍点陷阱**：非凸曲面上存在大量鞍点，当 Hessian 矩阵不正定时，纯牛顿法会被强烈吸引到鞍点甚至极大值点。
#### 二、工业解决方案
   - **拟牛顿法（如 L-BFGS）**：不显式计算 Hessian 矩阵，利用最近若干步的梯度变化差值向量逼近逆矩阵，空间复杂度降至 $O(md) = O(d)$。
   - **海森向量积（Hessian-Free / HVP）**：利用恒等式 $\mathbf{H}\mathbf{v} = \nabla (\nabla L \cdot \mathbf{v})$，通过两次反向传播直接计算矩阵与向量乘积，完全避免构造 $d \times d$ 矩阵。
   - **对角线近似（Adam / RMSprop）**：仅保留 Hessian 矩阵的对角线元素（用梯度平方即二阶矩进行自适应步长缩放），在 $O(d)$ 复杂度内吸收二阶曲率红利。

### 📌 练习 5：为什么在 `squared_loss` 函数中需要使用 `reshape` 函数？

> [!warning] 核心结论：防止隐式广播机制（Broadcasting）将向量减法错误展开为二维大矩阵。

#### 一、形状不一致的根源
   - 预测值 `y_hat` 经过矩阵乘法后为二维列向量：形状为 `[batch_size, 1]`；
   - 标签 `y` 从数据集读取时通常为一维向量：形状为 `[batch_size]`。
#### 二、不写 `reshape` 的灾难性后果
   - 若直接执行 `y_hat - y`，PyTorch 不会报错，而是触发广播机制，生成一个 `[batch_size, batch_size]` 的二维矩阵！
   - 例如 `batch_size = 256` 时，原本只需计算 256 个样本的误差，却算出了 $256 \times 256 = 65,536$ 个交叉元素（包含第 $i$ 个预测与第 $j$ 个标签之间的无意义差值）。
   - 损失被极度放大，梯度受到严重污染，显存飙升，且没有任何错误提示（最危险的静默 Bug）。
#### 三、解决方案
   - `y.reshape(y_hat.shape)` 显式将标签重塑为 `[batch_size, 1]`，保证点对点元素相减。

### 📌 练习 6：尝试使用不同的学习率，观察损失函数值下降的快慢

> [!note] 核心结论：学习率决定了每步更新的步长，过小导致停滞，过大导致震荡甚至指数爆炸（NaN）。

#### 一、四种典型学习率的表现规律
- **学习率过小（如 `lr = 0.0001`）**：
   - 损失下降极慢，3 个 Epoch 过去损失仅降低微量百分点，参数几乎停留在初始化附近。
- **学习率适中（如 `lr = 0.03`）**：
   - 损失呈平滑的指数级衰减，在 3 个 Epoch 内从约 10 迅速降至 $10^{-4}$ 级别，精确咬合真实参数。
- **学习率偏大（如 `lr = 0.5`）**：
   - 步长过大越过谷底，在山谷两侧来回振荡，损失出现忽高忽低的反弹。
- **学习率严重过大（如 `lr = 5.0`）**：
   - 步长突破了收敛的数学极限（$\eta \ge 2/\lambda_{\max}$），每一步越跳越远，损失瞬间爆炸为 `inf` 随后变为 `nan`（溢出崩溃）。

### 📌 练习 7：如果样本个数不能被批量大小整除，`data_iter` 函数的行为会有什么变化？

> [!note] 核心结论：最后一个批次会变为“样本不足的残缺批次”，样本数小于 `batch_size`。

#### 一、底层切片截断机制
   - 凭借 `indices[i: min(i + batch_size, num_examples)]` 中的 `min` 函数截断，避免了下标越界。
   - 例如 $1000$ 个样本且 `batch_size = 32` 时，前 31 个批次各有 32 个样本，最后一个批次只有剩余的 $8$ 个样本。
#### 二、对手写优化器步长的影响
   - 手写优化器 `sgd` 中参数除以固定的 `batch_size`（如 32）。最后一个批次求和梯度仅包含 8 个样本，除以 32 会导致其实际学习步长缩减为原先的 $\frac{8}{32} = \frac{1}{4}$。
#### 三、工业级处理方案（PyTorch `DataLoader`）
   - `drop_last=False`（默认）：保留最后残缺的批次；
   - `drop_last=True`：直接舍弃不足一个完整 batch 的零头数据。在包含批归一化（BatchNorm）或多卡分布式同步时必须设为 True，防止形状不匹配或方差计算崩溃。
