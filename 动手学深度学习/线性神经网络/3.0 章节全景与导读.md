### 2. 深度学习训练的标准四部曲

无论是简单的线性模型还是后续的卷积神经网络（CNN）、循环神经网络（RNN）或 Transformer，所有深度学习任务都共享完全一致的核心训练范式：

1. **准备数据**：小批量随机读取（`DataLoader`），将原始输入转化为张量特征 $\mathbf{X}$ 与目标标签 $\mathbf{y}$。
2. **定义模型**：建立将输入映射为输出的前向计算图（如 $\hat{\mathbf{y}} = \mathbf{X}\mathbf{w} + b$）。
3. **定义损失函数**：量化预测值 $\hat{\mathbf{y}}$ 与真实值 $\mathbf{y}$ 之间的差距（回归用均方误差 MSE，分类用交叉熵 Cross-Entropy）。
4. **优化算法**：基于反向传播计算的梯度更新参数（小批量随机梯度下降 SGD）：
   $$\mathbf{w} \leftarrow \mathbf{w} - \frac{\eta}{|\mathcal{B}|} \sum_{i \in \mathcal{B}} \nabla_{\mathbf{w}} l^{(i)}(\mathbf{w}, b)$$

## 核心公式速查

| 概念 | 线性回归 (3.1 ~ 3.3) | softmax 回归 (3.4 ~ 3.7) |
| :--- | :--- | :--- |
| **模型输出** | $\hat{y} = \mathbf{w}^\top \mathbf{x} + b$ （连续实数） | $\hat{\mathbf{y}} = \mathrm{softmax}(\mathbf{o})$，其中 $o_i = \mathbf{w}_i^\top \mathbf{x} + b_i$ （概率分布） |
| **激活函数** | 无（线性仿射变换） | $\hat{y}_j = \frac{\exp(o_j)}{\sum_k \exp(o_k)}$ |
| **损失函数** | 均方误差：$l = \frac{1}{2}(\hat{y} - y)^2$ | 交叉熵：$l = -\sum_j y_j \log \hat{y}_j = -\log \hat{y}_{\mathrm{label}}$ |
| **概率视角** | 假设标签噪声服从高斯分布 $\mathcal{N}(0, \sigma^2)$ 时的极大似然 | 多项分布假设下的极大似然估计 |
| **梯度形式** | $\frac{\partial l}{\partial \mathbf{w}} = (\hat{y} - y) \mathbf{x}$ | $\frac{\partial l}{\partial \mathbf{o}} = \hat{\mathbf{y}} - \mathbf{y}$ （预测概率减真实分布，形式与回归完全对应！） |
