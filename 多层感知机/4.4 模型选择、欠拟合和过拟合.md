# 模型选择、欠拟合和过拟合

在机器学习的实践中，我们最关心的并不是模型在已知训练数据上的得分，而是它在**未知的新样本上的泛化能力（Generalization）**。

本节我们将系统建立统计学习理论中关于**训练误差、泛化误差、模型容量、欠拟合与过拟合**的核心概念，并基于高阶多项式拟合实验，在代码层面复现模型容量如何戏剧性地决定学习成败。

```python
import math
import numpy as np
import torch
from torch import nn
from d2l import torch as d2l
```

---

## 一、训练误差 vs 泛化误差

* **训练误差（Training Error）**：模型在**训练数据集**上计算得到的误差（经验风险 Empirical Risk）。
* **泛化误差（Generalization Error）**：模型应用在从底层数据生成总体分布中抽取的**任意无限多未知测试样本**上的期望误差（期望风险 Expected Risk）。

在理想的独立同分布（i.i.d.）假设下，训练数据和测试数据来自于同一个数据生成分布 $P(X, Y)$。
然而，因为训练集样本量有限，**训练误差的降低并不必然代表泛化误差的降低**。当模型过于强大时，它完全有能力死记硬背训练集的特征乃至噪声，从而导致灾难性的泛化崩塌。

---

## 二、模型选择与评估数据集划分

为了无偏地估计泛化误差并挑选最优超参数，我们必须对数据进行严格的物理隔离：

```
整个数据集 (Dataset)
┌──────────────────────────────────────────────┬─────────────────────────┐
│              训练数据 (Training Set)          │  测试集 (Test Set)       │
│                                              │  (严禁参与训练与调参，    │
│  ┌─────────────────────────┬───────────────┐ │   仅作期末终考)          │
│  │ 实际训练集 (Train Fold) │ 验证集 (Val)  │ │                         │
│  │ (计算梯度反向传播)      │ (挑选超参数)  │ │                         │
│  └─────────────────────────┴───────────────┘ │                         │
└──────────────────────────────────────────────┴─────────────────────────┘
```

1. **训练集（Training Set）**：用于训练模型参数（$\mathbf{W}, \mathbf{b}$）；
2. **验证集（Validation Set）**：**不可用于反向传播求梯度**，专门用于评估模型在未知分布上的表现，以决定超参数选择（隐藏层数、单元数、学习率等）或执行早停（Early Stopping）；
3. **测试集（Test Set）**：在模型开发、架构设计、超参数调优完全敲定之前，**严禁触碰**。它用于终极无偏评估模型的真实泛化指标。

### $K$ 折交叉验证（$K$-fold Cross-Validation）
当数据量极度稀缺、无法承担划分出独立的固定验证集时，$K$ 折交叉验证是工业界标准解决方案：
* 将原始训练数据随机均分为 $K$ 个不重叠的子集（通常 $K=5$ 或 $10$）；
* 执行 $K$ 轮模型训练：在第 $i$ 轮中，选用第 $i$ 个子集作为验证集，其余 $K-1$ 个子集合并作为训练集；
* 最终的验证误差取这 $K$ 次验证误差的**算术平均值**。

## 三、欠拟合 vs 过拟合与模型容量

![[capacity-vs-error.svg]]

上图展现了深度学习中最经典的一组物理规律：
* **欠拟合（Underfitting）**：模型容量不足（模型过于简单），无法捕捉数据的真实潜在规律。表现为：**训练误差与泛化误差均居高不下**。
* **过拟合（Overfitting）**：模型容量过大（参数过多、特征过于复杂），模型把训练样本中的偶然噪声与采样偏差当成了全局本质规律。表现为：**训练误差极低（接近 0），但泛化误差高企并大幅反弹**。
* **泛化差距（Generalization Gap）**：泛化误差与训练误差之间的差值。随着模型容量的提升，泛化差距会单调扩大。

> [!note] 统计学习理论中的模型容量度量
> 传统的统计学习理论使用 **VC 维（Vapnik-Chervonenkis Dimension）** 来形式化界定函数类的复杂度。VC 维衡量的是一个模型能够将空间中任意散布的点集完全打散（Shatter）的能力。深层神经网络的参数量往往远大于样本量，但现代深度学习通过隐式正则化依然具备良好泛化能力。

## 四、代码实测：多项式拟合实验

我们构造一个真实的三阶多项式数据生成模型：

$$y = 5 + 1.2x - 3.4\frac{x^2}{2!} + 5.6 \frac{x^3}{3!} + \epsilon, \quad \text{其中 } \epsilon \sim \mathcal{N}(0, 0.1^2)$$

在实验中，我们将阶数扩展到 20 阶多项式，分别模拟：
1. **正常拟合**：提供前 4 阶特征（阶数与生成函数匹配）；
2. **欠拟合**：仅提供前 2 阶线性特征（容量严重不足）；
3. **过拟合**：提供完整的 20 阶特征，且仅给极少量（100 个）训练样本。

```python
max_degree = 20  # 多项式的最大阶数
n_train, n_test = 100, 100
true_w = np.zeros(max_degree)
true_w[0:4] = np.array([5, 1.2, -3.4, 5.6])

features = np.random.normal(size=(n_train + n_test, 1))
np.random.shuffle(features)
# 生成多项式特征矩阵: x^i / i!
poly_features = np.power(features, np.arange(max_degree).reshape(1, -1))
for i in range(max_degree):
    poly_features[:, i] /= math.gamma(i + 1)  # gamma(n) = (n-1)!

labels = np.dot(poly_features, true_w)
labels += np.random.normal(scale=0.1, size=labels.shape)

# 转换为 PyTorch 张量
true_w, features, poly_features, labels = [torch.tensor(x, dtype=torch.float32) 
    for x in [true_w, features, poly_features, labels]]
```

### 定义训练与评估辅助函数

```python
def evaluate_loss(net, data_iter, loss):
    metric = d2l.Accumulator(2)
    for X, y in data_iter:
        out = net(X)
        y = y.reshape(out.shape)
        l = loss(out, y)
        metric.add(l.sum(), l.numel())
    return metric[0] / metric[1]

def train(train_features, test_features, train_labels, test_labels, num_epochs=400):
    loss = nn.MSELoss(reduction='none')
    input_shape = train_features.shape[-1]
    net = nn.Sequential(nn.Linear(input_shape, 1, bias=False))
    batch_size = min(10, train_labels.shape[0])
    train_iter = d2l.load_array((train_features, train_labels.reshape(-1, 1)), batch_size)
    test_iter = d2l.load_array((test_features, test_labels.reshape(-1, 1)), batch_size, is_train=False)
    trainer = torch.optim.SGD(net.parameters(), lr=0.01)
    animator = d2l.Animator(xlabel='epoch', ylabel='loss', yscale='log',
                            xlim=[1, num_epochs], ylim=[1e-3, 1e2],
                            legend=['train', 'test'])
    for epoch in range(num_epochs):
        d2l.train_epoch_ch3(net, train_iter, loss, trainer)
        if epoch == 0 or (epoch + 1) % 20 == 0:
            animator.add(epoch + 1, (evaluate_loss(net, train_iter, loss),
                                     evaluate_loss(net, test_iter, loss)))
    print('weight:', net[0].weight.data.numpy())
```

### 1. 正常拟合（匹配模型阶数）
输入特征选择前 4 维（即 $1, x, \frac{x^2}{2!}, \frac{x^3}{3!}$）：

```python
train(poly_features[:n_train, :4], poly_features[n_train:, :4],
      labels[:n_train], labels[n_train:])
```
* **实验现象**：训练损失与测试损失双双平滑下跌，最终收敛至相近的极低数值（接近噪声方差 $0.01$）。学到的权重高度吻合真实值 $[5, 1.2, -3.4, 5.6]$。

### 2. 欠拟合（线性模型）
输入特征仅选择前 2 维（即 $1, x$）：

```python
train(poly_features[:n_train, :2], poly_features[n_train:, :2],
      labels[:n_train], labels[n_train:])
```
* **实验现象**：即使迭代 400 轮，训练损失与测试损失都维持在很高的平台期（约为 $10^0 \sim 10^1$），无法继续下降。模型无力捕捉二阶和三阶项的弯曲规律。

### 3. 过拟合（高阶多项式，20 阶）
输入特征提供全部 20 维，且训练样本仅有 100 个：

```python
train(poly_features[:n_train, :], poly_features[n_train:, :],
      labels[:n_train], labels[n_train:], num_epochs=1500)
```
* **实验现象**：训练损失被优化器压得极低，但测试损失严重反弹上翘，与训练损失之间拉开了数个数量级的巨大鸿沟。模型为了降低训练损失，学到了剧烈震荡的极端高阶权重。

## 小结与核心提炼

> [!tip] 课程精髓提炼（融合李沐老师 `notebooks/209` 核心总结）

* **泛化是唯一衡量标准**：在机器学习中，降低训练误差是极其容易的（大模型死记硬背即可），困难的是使未知样本的泛化误差最小。
* **过拟合与欠拟合的判别法则**：
  * **欠拟合**：训练误差大，模型容量不足，对策是**增加模型容量（增加层数、神经元数、构造多项式特征）**；
  * **过拟合**：训练误差极小但测试误差极大，对策是**收集更多数据、降低模型复杂度、引入正则化（权重衰减、Dropout）**。
* **数据集划分铁律**：验证集绝不能参与反向传播，测试集在最终交付前绝不可偷看，否则会造成严重的数据泄露与过分乐观的虚假评估。

## 练习

### 📌 练习 1：多项式回归的解析解（闭式解）
> **问题**：多项式回归问题能否像线性回归一样写出闭式解析解？

**数学推导与解答**：
可以。多项式回归本质上是**特征经过多项式基函数非线性变换后的线性模型**。
设单特征样本 $x_i$，其多项式特征向量为 $\boldsymbol{\phi}(x_i) = [1, x_i, x_i^2, \dots, x_i^d]^\top$。
构造全局设计矩阵 $\boldsymbol{\Phi} \in \mathbb{R}^{n \times (d+1)}$：
$$
\boldsymbol{\Phi} = \begin{bmatrix}
1 & x_1 & x_1^2 & \dots & x_1^d \\
1 & x_2 & x_2^2 & \dots & x_2^d \\
\vdots & \vdots & \vdots & \ddots & \vdots \\
1 & x_n & x_n^2 & \dots & x_n^d
\end{bmatrix}
$$
目标是最小化平方误差损失：$\min_{\mathbf{w}} \|\boldsymbol{\Phi}\mathbf{w} - \mathbf{y}\|_2^2$。
根据正规方程（Normal Equations），若 $\boldsymbol{\Phi}^\top \boldsymbol{\Phi}$ 可逆（当样本数 $n > d$ 且特征互不共线时成立），其闭式解为：
$$
\mathbf{w}^* = (\boldsymbol{\Phi}^\top \boldsymbol{\Phi})^{-1} \boldsymbol{\Phi}^\top \mathbf{y}
$$
但当阶数 $d$ 较大时，该设计矩阵是著名的范德蒙德矩阵（Vandermonde Matrix），其条件数极其庞大，直接求逆会导致剧烈的数值不稳定性，因此实践中通常首选小批量梯度下降法求解。

---

### 📌 练习 2：多项式阶数与数据量对模型选择的影响
> **问题**：绘制训练损失与模型复杂度（多项式阶数）的关系，需要多高阶的多项式才能将训练损失降为 0？改变训练样本数量（如分别设为 20、100、1000），观察曲线有何不同？

**理论与实验分析**：
1. **训练损失降为 0 的临界条件**：
   - 设训练样本数量为 $n$。根据代数学基本定理，包含 $n$ 个独立可调参数的多项式（即 $n-1$ 阶多项式，参数包含偏置共 $n$ 个）能够严格通过笛卡尔坐标系中任意给定的 $n$ 个不重合样本点。
   - 因此，**只要多项式阶数达到 $n-1$ 阶，线性方程组有唯一精确解，训练损失即可精确等于 0**（插值现象）。
2. **训练样本量 $n$ 的影响**：
   - 当样本极少（如 $n=20$）：模型极易过拟合，即使是 5 阶多项式也会产生严重的泛化恶化；
   - 当样本极大（如 $n=1000$）：数据对高阶震荡产生了极强的锚定约束，此时即便使用 10 阶多项式，测试损失也能保持较低水平。**更多的数据是抵御过拟合最强有力的天然武器**。

---

### 📌 练习 3：特征缩放（$x^i / i!$）的数值意义
> **问题**：如果在构造多项式特征时不进行阶乘除法归一化（直接使用原始的 $x^i$ 而不是 $x^i / i!$），会发生什么？

**数值计算与梯度机理分析**：
1. **输入数值的跨数量级爆炸**：
   若 $x \approx 3$，当阶数 $i=10$ 时，$x^{10} \approx 59049$；而当 $x = 0.5$ 时，$x^{10} \approx 0.000976$。不同阶数特征之间的数值范围跨越了十几个数量级。
2. **损失曲面病态条件数（Ill-conditioned Surface）**：
   未经缩放的设计矩阵，其自相关矩阵的最大特征值与最小特征值之比（条件数）极其巨大。损失曲面呈现出极度狭长的扁平椭圆谷地。
3. **梯度爆炸与优化瘫痪**：
   高阶项参数的梯度正比于 $x^i$，在反向传播时高阶梯度的剧烈冲击会导致优化器直接溢出发散（产生 `NaN`）。引入 Taylor 展开中的阶乘因子 $\frac{1}{i!}$，能够利用阶乘极快的增长速度完全遏制高阶幂次的膨胀，保证所有特征维持在可控的数值量级。
