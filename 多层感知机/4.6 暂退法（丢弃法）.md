# 暂退法（Dropout / 丢弃法）

在前面几节中，我们探讨了通过惩罚权重范数（$L_2$ 权重衰减）来限制模型容量的方法。

2014 年，深度学习先驱 Geoffrey Hinton 团队（Srivastava et al.）提出了一种专属于深度神经网络的非凡正则化技术——**暂退法（Dropout，曾译为丢弃法）**。该方法通过在训练过程中对神经元引入无偏随机扰动，极大地提升了模型的鲁棒性与泛化能力。

```python
import torch
from torch import nn
```

## 一、数学机理与无偏扰动推导

### 1. 注入噪声的正则化等价性
毕晓普（Bishop, 1995）在统计学上证明了一个优美定理：**在模型的输入特征上注入零均值的高斯噪声，在数学期望上等价于向损失函数中添加 Tikhonov（$L_2$ 权重衰减）正则化项！**
这启发了研究人员：既然输入噪声能平滑决策边界，那么**如果直接向网络深层的隐藏层中间表示注入噪声，能否达到更强大的深层特征解耦效果？**

### 2. 神经元共适应性（Co-adaptation）的破除
在标准的多层网络中，某些神经元可能会“寄生”在其他神经元之上——即某个神经元犯的错误被另一个神经元过度补偿，神经元之间形成了高度脆弱的复杂**协同共适应（Co-adaptation）**。
Dropout 在前向传播时**以固定概率 $p$ 随机将神经元置零**。由于任何神经元都无法预知自己的搭档在下一轮是否还“活着”，每个神经元被迫学习更加独立、健壮、富有通用表达力的特征。

---

### 3. 反向丢弃法（Inverted Dropout）的期望不变性

为了确保注入噪声时不改变前向传播的总体能量期望，标准实现采用**反向丢弃法（Inverted Dropout）**：

对于隐藏层输出向量中的任意神经元 $h$，以暂退概率 $p \in [0, 1)$ 进行随机掩码：
$$
h' = \begin{cases}
0, & \text{以概率 } p \\
\frac{h}{1 - p}, & \text{以概率 } 1 - p
\end{cases}
$$

#### 严密无偏期望证明：
我们计算经过扰动后的神经元 $h'$ 的数学期望 $\mathbb{E}[h']$：
$$
\begin{aligned}
\mathbb{E}[h'] &= P(\text{被置零}) \cdot 0 + P(\text{未被置零}) \cdot \frac{h}{1 - p} \\
&= p \cdot 0 + (1 - p) \cdot \frac{h}{1 - p} \\
&= \mathbf{h}
\end{aligned}
$$

> [!important] 为什么要在训练期除以 $(1 - p)$？
> 这一步设计极其精妙：
> * **早期 Dropout 做法**：训练时只做掩码 $h' = h$（置 0 或保留），但在测试时，必须手动将权重乘以 $(1 - p)$ 才能对齐激活值的统计尺度。
> * **现代反向丢弃法（Inverted Dropout）**：直接在**训练阶段**放大剩余未置零的神经元（除以 $1-p$）。这样在前向推断测试阶段，网络**完全不需要做任何后处理缩放**，直接关闭 Dropout 即可满血前向推断，大幅简化了部署流水线。

## 二、架构拓扑与训练/测试模式分离

![[dropout2.svg]]

如上图所示：
* **训练模式（`net.train()`）**：以概率 $p$ 随机断开隐藏层中的连接。每一轮迭代激活的其实是一个不同的子网络；
* **测试/评估模式（`net.eval()`）**：**必须完全禁用 Dropout！** 所有的连接全部保留，以确定性的状态输出稳定的预测结果。

## 三、从零开始实现 Dropout

我们手动实现底层的 `dropout_layer` 掩码算子：

```python
def dropout_layer(X, dropout):
    assert 0 <= dropout <= 1
    # 极端边界处理
    if dropout == 1:
        return torch.zeros_like(X)
    if dropout == 0:
        return X
    
    # 核心无偏掩码：生成 (0, 1) 均匀分布随机数，大于 dropout 的保留为 1，否则为 0
    mask = (torch.rand(X.shape) > dropout).float()
    return mask * X / (1.0 - dropout)
```

### 定义双隐藏层网络与前向流转

```python
num_inputs, num_outputs, num_hiddens1, num_hiddens2 = 784, 10, 256, 256
dropout1, dropout2 = 0.2, 0.5

class Net(nn.Module):
    def __init__(self, num_inputs, num_outputs, num_hiddens1, num_hiddens2, is_training=True):
        super(Net, self).__init__()
        self.num_inputs = num_inputs
        self.training = is_training
        self.lin1 = nn.Linear(num_inputs, num_hiddens1)
        self.lin2 = nn.Linear(num_hiddens1, num_hiddens2)
        self.lin3 = nn.Linear(num_hiddens2, num_outputs)
        self.relu = nn.ReLU()

    def forward(self, X):
        H1 = self.relu(self.lin1(X.reshape((-1, self.num_inputs))))
        # 仅在训练阶段应用 Dropout
        if self.training == True:
            H1 = dropout_layer(H1, dropout1)
        H2 = self.relu(self.lin2(H1))
        if self.training == True:
            H2 = dropout_layer(H2, dropout2)
        out = self.lin3(H2)
        return out
```

## 四、简洁实现（PyTorch `nn.Dropout` API）

在工业界，我们直接通过 `nn.Dropout(p)` 层构建多层感知机：

```python
net = nn.Sequential(
    nn.Flatten(),
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Dropout(0.2),            # 在第一个隐藏层后以 p=0.2 暂退
    nn.Linear(256, 256),
    nn.ReLU(),
    nn.Dropout(0.5),            # 在第二个隐藏层后以 p=0.5 暂退
    nn.Linear(256, 10)
)

def init_weights(m):
    if type(m) == nn.Linear:
        nn.init.normal_(m.weight, std=0.01)

net.apply(init_weights);
```

### 启动训练：
```python
num_epochs, lr, batch_size = 10, 0.5, 256
loss = nn.CrossEntropyLoss(reduction='none')
trainer = torch.optim.SGD(net.parameters(), lr=lr)
train_iter, test_iter = d2l.load_data_fashion_mnist(batch_size)

d2l.train_ch3(net, train_iter, test_iter, loss, num_epochs, trainer)
```

## 小结与核心提炼

> [!tip] 课程精髓提炼（融合李沐老师 `notebooks/211` 核心总结）

* **集成学习（Ensemble Learning）视角**：拥有 $H$ 个神经元的隐藏层，在 Dropout 机制下理论上能够生成 $2^H$ 个不同的子网络结构。每次训练一个 Batch 都在训练其中一个子网络，且所有子网络**共享权重**。最终在测试集上不带 Dropout 的前向推断，等价于对这 $2^H$ 个子网络预测概率的几何平均集成（Ensemble）！
* **经验暂退率设定法则**：
  * 靠近输入层的浅层隐藏层：由于主要提取通用基础特征，丢弃率宜设得较小（如 $p_1 = 0.1 \sim 0.2$）；
  * 靠近输出层的深层隐藏层：参数复杂度高，容易过拟合，丢弃率通常设得较大（如 $p_2 = 0.5$）。
* **测试期的确定性**：Dropout **仅在训练期生效**。在推理评估阶段必须显式切换为 `net.eval()`，绝不能在生产环境的单次预测中随机置零特征。

## 练习

### 📌 练习 1：暂退率 $p_1$ 与 $p_2$ 的调优消融实验
> **问题**：如果互换第一层和第二层的暂退率（例如 $p_1=0.5, p_2=0.2$），或者将两个暂退率均设为 0，会发生什么？

**深度机理分析**：
1. **$p_1=0.5, p_2=0.2$（深浅倒置）**：
   - 浅层包含的底层原始特征被粗暴地砍掉了一半，导致第一层向后传递的信息严重丢失，网络整体欠拟合风险骤增，最终测试集精度出现明显下跌。
2. **$p_1 = 0, p_2 = 0$（关闭 Dropout）**：
   - 训练损失下降极快，但在训练轮次增加后，训练损失与测试损失之间的泛化差距（Generalization Gap）显著拉大，模型展现出明确的过拟合趋势。

---

### 📌 练习 2：激活值方差的理论变化
> **问题**：在隐藏层未应用与应用 Dropout 时，该层中间激活值的方差会发生怎样的改变？

**严密方差推导**：
设原激活值为随机变量 $H$。
引入掩码伯努利变量 $M \sim \text{Bernoulli}(1-p)$，使得扰动后变量为 $H' = \frac{M}{1-p} H$。
假定掩码与输入相互独立，根据方差分解定理：
$$
\operatorname{Var}(H') = \mathbb{E}[(H')^2] - (\mathbb{E}[H'])^2
$$
其中第二项因期望无偏保持为 $(\mathbb{E}[H])^2$。计算第一项：
$$
\mathbb{E}[(H')^2] = \mathbb{E}\left[ \left(\frac{M}{1-p}\right)^2 \right] \mathbb{E}[H^2] = \frac{1-p}{(1-p)^2} \mathbb{E}[H^2] = \frac{1}{1-p} \mathbb{E}[H^2]
$$
代入方差公式整理得：
$$
\operatorname{Var}(H') = \frac{\operatorname{Var}(H)}{1-p} + \frac{p}{1-p} (\mathbb{E}[H])^2 > \operatorname{Var}(H)
$$
**结论**：**应用 Dropout 会显著放大中间激活值的方差！** 注入的这种可控随机方差，迫使后序层学习对于神经元波动高度不敏感的容错表征。

---

### 📌 练习 3：为什么测试阶段通常不用 Dropout？
> **问题**：为什么在模型推断和测试阶段绝对不应使用 Dropout？

**系统可靠性与方差分析**：
1. **确定性输出原则**：在自动驾驶、医疗决策或工业检测等实际落地场景中，同一个测试样本输入模型必须给出**唯一确定且稳定**的预测结果。若在测试期引入随机 Dropout，模型会对同一张图片在不同时刻给出相互矛盾的预测。
2. **方差消除与最优集成**：测试期保留全部神经元并恢复全连接，在数学上等价于所有可能子网络的最优几何平均，此时预测方差降至最低，精度达到峰值。

---

### 📌 练习 4：Dropout 与权重衰减的联合使用
> **问题**：如果将 Dropout 与 $L_2$ 权重衰减同时应用于同一个模型，会发生什么？它们的效果是简单叠加吗？

**现代深度网络实战经验**：
* 两种正则化机理不同（权重衰减约束参数范数平滑曲率，Dropout 通过特征随机缺失破坏共适应），在现代大模型与深层架构（如 Transformer、ResNet）中**通常联合使用**。
* **协同效应与过度正则化陷阱**：
  二者的正则化强度并非线性无关。若同时设置过大的 `weight_decay`（如 $0.05$）和过大的 Dropout（如 $0.5$），双重强力约束会使模型的有效容量大幅低于任务底线，导致模型发生严重的**欠拟合（Underfitting）**。工业界通常设定温和的权重衰减（如 $10^{-4}$），配合小幅度的 Dropout（$0.1 \sim 0.2$）。

---

### 📌 练习 5：对权重矩阵施加 Dropout（DropConnect）
> **问题**：如果不是对隐藏单元激活值进行随机置零，而是直接对权重矩阵 $\mathbf{W}$ 的连接进行随机置零，会发生什么？

**DropConnect 机制剖析**：
这正是 Wan et al. (2013) 提出的 **DropConnect** 算法。
* **区别**：Dropout 是将隐藏层的输出向量行/列整体置零，而 DropConnect 是将权重矩阵中的独立连边以概率 $p$ 置零（将稀疏性推向连接级）。
* **理论对比**：DropConnect 的自由度更高（子网络数量从 $2^H$ 激增至 $2^{d \times H}$），正则化能力极强；但其致命弱点在于**无法直接利用高效的连续张量乘法（GEMM）硬件加速**，计算速度显著低于标准 Dropout，因此在主流框架中未成为默认选择。
