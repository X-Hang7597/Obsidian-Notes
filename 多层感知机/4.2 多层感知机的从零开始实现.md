# 多层感知机的从零开始实现

在 [[4.1 多层感知机|4.1 节]] 中，我们从理论上剖析了隐藏层与非线性激活函数的核心价值。本节我们将**从底层张量开始，亲手搭建一个完整的单隐藏层多层感知机**，并继续使用 Fashion-MNIST 数据集进行分类实测，直观对比其相比第 3 章 Softmax 回归的拟合能力提升。

```python
import torch
from torch import nn
from d2l import torch as d2l
```

```python
batch_size = 256
train_iter, test_iter = d2l.load_data_fashion_mnist(batch_size)
```

---

## 一、初始化模型参数

Fashion-MNIST 中每个样本都是 $28 \times 28 = 784$ 的灰度图像，共有 10 个类别。
我们将实现一个**单隐藏层多层感知机**：
* 输入特征维度：`num_inputs = 784`
* 隐藏层单元数：`num_hiddens = 256`（选择 256 作为一个典型的宽度设定，计算硬件友好）
* 输出类别数：`num_outputs = 10`

由于网络包含两个线性层，我们需要维护两套独立的权重矩阵与偏置向量：
1. **隐藏层参数**：$\mathbf{W}_1 \in \mathbb{R}^{784 \times 256}, \mathbf{b}_1 \in \mathbb{R}^{1 \times 256}$
2. **输出层参数**：$\mathbf{W}_2 \in \mathbb{R}^{256 \times 10}, \mathbf{b}_2 \in \mathbb{R}^{1 \times 10}$

```python
num_inputs, num_outputs, num_hiddens = 784, 10, 256

# 隐藏层参数
W1 = nn.Parameter(torch.randn(num_inputs, num_hiddens, requires_grad=True) * 0.01)
b1 = nn.Parameter(torch.zeros(num_hiddens, requires_grad=True))

# 输出层参数
W2 = nn.Parameter(torch.randn(num_hiddens, num_outputs, requires_grad=True) * 0.01)
b2 = nn.Parameter(torch.zeros(num_outputs, requires_grad=True))

params = [W1, b1, W2, b2]
```

### 关键机制解析：
* **`nn.Parameter` 的作用**：在底层为普通的张量封装上参数属性。当后续需要将其传递给优化器或嵌入模块时，PyTorch 会将其自动识别为可学习参数。
* **权重初始化尺度（乘以 0.01）**：使用标准正态分布随机初始化时，乘以 $0.01$ 将初始权重缩放到较小幅度，防止前向传播时激活值方差过大进入饱和区，也为梯度的稳定传递提供保障。

---

## 二、激活函数实现

我们基于基础张量算子手动实现 **ReLU** 激活函数：

$$\operatorname{ReLU}(X) = \max(X, 0)$$

```python
def relu(X):
    a = torch.zeros_like(X)
    return torch.max(X, a)
```

> [!note] 底层算子说明
> `torch.max(X, a)` 执行逐元素的比较求最大值操作。由于无需计算指数，整个过程在 CPU/GPU 上是以极高的吞吐向量化执行的。

---

## 三、定义网络前向传播

网络的前向推演包含三个步骤：展平输入 $\to$ 隐藏层计算与激活 $\to$ 输出层未归一化得分。

```python
def net(X):
    # 1. 展平图像: (B, 1, 28, 28) -> (B, 784)
    X = X.reshape((-1, num_inputs))
    # 2. 隐藏层仿射变换与 ReLU 激活: (B, 784) @ (784, 256) -> (B, 256)
    H = relu(X @ W1 + b1)
    # 3. 输出层仿射变换: (B, 256) @ (256, 10) -> (B, 10)
    return (H @ W2 + b2)
```

### 张量维度与内存流转：
$$\begin{aligned}
\mathbf{X} &: (256, 1, 28, 28) \xrightarrow{\text{reshape}} (256, 784) \\
\mathbf{H} &: \operatorname{ReLU}(\mathbf{X}\mathbf{W}_1 + \mathbf{b}_1) \in \mathbb{R}^{256 \times 256} \\
\mathbf{O} &: \mathbf{H}\mathbf{W}_2 + \mathbf{b}_2 \in \mathbb{R}^{256 \times 10}
\end{aligned}$$

> [!important] 为什么模型输出层没有调用 Softmax？
> 重温我们在 3.6 和 3.7 节得出的结论：为了防止极小概率引发数值下溢，模型只输出原始得分 Logits $\mathbf{O}$，Softmax 及其对数化简全部委托给底层的交叉熵损失函数。

---

## 四、损失函数与训练流程

由于我们在 3.6 节定义的训练函数 `d2l.train_ch3` 是完全通用的，它对多层感知机与 Softmax 回归一视同仁。我们直接复用该训练流水线：

```python
loss = nn.CrossEntropyLoss(reduction='none')

num_epochs, lr = 10, 0.1
updater = torch.optim.SGD(params, lr=lr)

d2l.train_ch3(net, train_iter, test_iter, loss, num_epochs, updater)
```

训练完成后，我们可以使用 `predict_ch3` 直观验证模型对测试样本的预测效果：

```python
d2l.predict_ch3(net, test_iter)
```

## 小结与核心提炼

> [!tip] 课程精髓提炼（融合李沐老师 `notebooks/208` 核心总结）

* **从零实现的复杂度跃迁**：手动实现单隐藏层 MLP 虽然依然直观，但参数管理量从原来的 2 个（$W, b$）翻倍到 4 个（$W_1, b_1, W_2, b_2$）。如果层数达到几十层，手动维护参数与前向图将变得不可承受，这也是工业界转向高阶 API（如 `nn.Sequential`）的核心动因。
* **MLP 的性能上限与局限性**：
  * 在 Fashion-MNIST 上，单隐藏层 MLP 的测试集准确率能从 Softmax 回归的约 $82\%$ 提升至约 $85\%$；
  * **为什么提升幅度没有想象中大？** 李沐老师指出：因为全连接 MLP 依然使用 `X.reshape((-1, 784))` 把图像强行拉平成一维向量，**彻底破坏了图像像素间的二维邻域空间几何相关性**。要实现视觉准确率的质的飞跃，必须依赖后续第 6 章的卷积神经网络（CNN）。

## 练习

### 📌 练习 1：超参数 `num_hiddens` 的敏感度与调优策略
> **问题**：尝试改变 `num_hiddens` 的值（如设为 32、64、512、1024），观察对收敛速度和测试集精度的影响。如何确定该超参数的最优值？

**深度解析**：
1. **隐藏单元过少（如 32 或 64）**：
   - 隐藏层瓶颈过窄，网络信息容量（Information Capacity）受限，特征投影维度不足，容易产生**欠拟合（Underfitting）**，最终测试集精度难以突破 83%。
2. **隐藏单元过多（如 1024 或 2048）**：
   - 模型参数量激增，前向与反向传播的矩阵乘法显存与算力开销成倍放大；
   - 模型的拟合容量过大，若训练轮数较多且无正则化，极易产生**过拟合（Overfitting）**，训练损失极低但测试损失开始反弹。
3. **最优值确定方案**：
   - 超参数无法通过反向传播自动求导，必须在**独立的验证集（Validation Set）**上进行系统性网格搜索或贝叶斯优化，依据验证集精度的拐点来确定最优容量。

---

### 📌 练习 2：增加隐藏层层数的影响
> **问题**：尝试添加更多的隐藏层（如构建双隐藏层：$784 \to 256 \to 128 \to 10$），查看对结果有何影响？

**深度解析**：
1. **表达能力增强**：理论上更深的网络能学习到分层阶梯式的特征抽象（浅层提取局部边缘，深层组合高阶抽象），决策边界更加精细。
2. **优化难度增加**：
   - 随着层数增加，参数更新的反向传播链条拉长；
   - 若学习率或初始化不匹配，深层网络更容易遭遇梯度消失或梯度爆炸；
   - 在数据量有限的简单任务（如 Fashion-MNIST）上，双隐藏层 MLP 若未引入良好的正则化，相比单隐藏层很难取得肉眼可见的泛化增益，反而训练耗时显著拉长。

---

### 📌 练习 3：学习率与模型架构的联动
> **问题**：改变学习率对结果有何影响？保持模型架构不变，学习率设置为多少会获得更好的结果？

**深度解析**：
* 学习率 $\eta$ 决定了梯度向量上的位移步长：
  - $\eta = 0.01$ 时收敛过慢，10 个 Epoch 结束时模型尚未到达谷底平稳区；
  - $\eta = 0.1 \sim 0.3$ 时损失稳步单调下降，达到最佳平衡点；
  - $\eta \ge 1.0$ 时损失曲线开始出现剧烈上下震荡甚至发散。
* 当隐藏层变宽或变深时，损失曲面的曲率（Hessian 矩阵最大特征值）会发生变化，通常需要微调甚至适度降低学习率以确保平稳收敛。

---

### 📌 练习 4：联合超参数优化与经验最佳配置
> **问题**：同时调整学习率、隐藏层数、每层隐藏单元数，你能达到的最佳测试精度是多少？

**实测经验结论**：
* 在不引入卷积网络的前设下，MLP 在 Fashion-MNIST 的理论上限通常在 **$86\% \sim 88\%$** 之间。
* 经典稳定配置：采用双隐藏层架构（$784 \to 256 \to 128 \to 10$），学习率设为 $0.2$，批量大小 256，训练 15~20 轮，并配合权重衰减，可达到约 $87.5\%$ 的测试精度。

---

### 📌 练习 5：为什么联合优化超参数极具挑战性？
> **问题**：为什么联合优化所有超参数涉及更具挑战性的策略？

**系统理论剖析**：
1. **维度灾难（Curse of Dimensionality）**：
   若独立调优 $M$ 个超参数，每个超参数尝试 $K$ 个候选值，总试验次数呈指数级膨胀：$K^M$。全空间遍历在算力上不可行。
2. **参数间的非凸耦合与强相互作用（Coupling Effect）**：
   超参数之间不是相互正交的，而是高度联动的。例如：改变批量大小 $B$ 必须联动改变学习率 $\eta$（线性缩放法则）；增加网络深度往往必须联动降低学习率或引入更严苛的初始化。一个超参数的改变会直接导致其他超参数的最优区间发生剧烈漂移。
3. **黑盒评估代价极高（Expensive Black-box Function）**：
   超参数的目标函数是“完整训练一次模型后的验证集指标”，单次评估需要消耗数分钟乃至数小时的 GPU 算力，无法直接计算梯度。

---

### 📌 练习 6：通用超参数调优策略的架构组件
> **问题**：如果要构建一个通用的超参数自动化调优策略，它应该包含哪些核心组件？

**工业级 AutoML 超参优化框架必备组件**：
1. **搜索空间定义器（Search Space Definition）**：定义各超参数的类型与取值分布（连续对数均匀分布、离散整数集合等）；
2. **采样/优化算法引擎（Search Algorithm）**：
   - 简单策略：随机搜索（Random Search，实践中通常显著优于网格搜索）；
   - 进阶策略：贝叶斯优化（Bayesian Optimization / TPE，用高斯过程或树模型拟合参数与精度的代理函数，探索与利用平衡）；
3. **早停评估与调度器（Early Stopping Scheduler）**：
   - 类似 Hyperband 或 ASHA 算法，在训练初期（如第 2 轮）快速淘汰表现极差的参数配置，把算力资源集中倾斜给表现优异的种子选手；
4. **验证集与指标评估器（Objective Evaluator）**：提供无偏、稳定的验证集评估逻辑，防止测试集数据泄露。
