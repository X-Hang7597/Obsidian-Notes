# 多层感知机的从零开始实现

在 [[4.1 多层感知机|4.1 节]] 中，我们从理论上推导了隐藏层与非线性激活函数的核心数学价值。
正如我们在第 3 章中从零开始实现线性回归与 Softmax 回归一样，**真正理解一个深度网络最好的方式，就是不依赖框架的高层封装，从底层张量乘法和自动微分开始亲手将它搭建起来**。

本节我们将使用在 [[3.5 图像分类数据集|3.5 节]] 中引入的 Fashion-MNIST 服饰图像数据集，从零构建一个单隐藏层的多层感知机（MLP），并实现完整的训练、评估与预测流水线。

```python
import torch
from torch import nn
from d2l import torch as d2l
```

```python
batch_size = 256
train_iter, test_iter = d2l.load_data_fashion_mnist(batch_size)
```

---

## 一、初始化模型参数

### 1. 维度设计与硬件考量

回顾 Fashion-MNIST 数据集：
* 每张图像的高和宽均为 28 像素，展平后为长度为 $28 \times 28 = 784$ 的一维特征向量；
* 数据集共有 10 个服饰类别。

因此，输入特征维度 `num_inputs = 784`，最终分类输出维度 `num_outputs = 10`。

对于隐藏层的宽度（隐藏单元数），我们选择 `num_hiddens = 256`：

> [!note] 为什么通常选择 2 的幂次方（如 128, 256, 512）作为隐藏单元数？
> 这是一个典型的计算硬件工程设计考虑：
> 1. **内存与显存对齐（Memory Alignment）**：现代 CPU 的缓存行（Cache Line，通常为 64 字节）以及 GPU 的全局内存事务是以 32 字节或 128 字节为边界对齐的；
> 2. **并行线程块调度（Warp Scheduling）**：NVIDIA GPU 的基本调度单位是 Warp（包含 32 个并行线程）。将张量维度设为 32 的整数倍（如 $256 = 32 \times 8$），能够确保 GPU 的 CUDA Core 和 Tensor Core 矩阵乘法单元满负荷运转，避免产生尾随计算空闲（Tail Effect）。

### 2. 权重矩阵与偏置向量的分配

一个包含单隐藏层的多层感知机，本质上由**两个连续的仿射变换**串联而成。因此我们需要分配两组独立的参数：

1. **第一层（输入层 $\to$ 隐藏层）**：
   * 权重矩阵：$\mathbf{W}_1 \in \mathbb{R}^{784 \times 256}$
   * 偏置向量：$\mathbf{b}_1 \in \mathbb{R}^{1 \times 256}$
2. **第二层（隐藏层 $\to$ 输出层）**：
   * 权重矩阵：$\mathbf{W}_2 \in \mathbb{R}^{256 \times 10}$
   * 偏置向量：$\mathbf{b}_2 \in \mathbb{R}^{1 \times 10}$

```python
num_inputs, num_outputs, num_hiddens = 784, 10, 256

# 隐藏层参数
W1 = nn.Parameter(torch.randn(num_inputs, num_hiddens, requires_grad=True) * 0.01)
b1 = nn.Parameter(torch.zeros(num_hiddens, requires_grad=True))

# 输出层参数
W2 = nn.Parameter(torch.randn(num_hiddens, num_outputs, requires_grad=True) * 0.01)
b2 = nn.Parameter(torch.zeros(num_outputs, requires_grad=True))

params = [W1, b1, W2, b2]
```

### 关键语法与底层机制解析：
* **`nn.Parameter` 的作用**：普通的 `torch.Tensor` 只是纯粹的数据容器；而 `nn.Parameter` 是 `Tensor` 的一个子类。将其封装后，PyTorch 会显式向底层模块注册该张量为**可学习参数**，在后续调用优化器（如 `optim.SGD(params)`）时能够被自动追踪和管理。
* **`requires_grad=True`**：显式通知 Autograd 自动微分引擎，在反向传播时为这 4 个张量构建计算图节点，并在 `.grad` 属性中累加偏导数。
* **权重缩放因子 `* 0.01`**：`torch.randn` 生成均值为 0、方差为 1 的标准正态分布。直接使用标准差 1.0 的初始权重会导致前向传播的输出方差迅速膨胀，乘以 $0.01$ 将参数约束在较小的紧致区域，确保初始梯度稳定（具体数学原理将在 4.8 节展开推导）。
* **偏置初始化为 0**：偏置不存在破坏神经元对称性的问题，初始化为全零是通行的标准做法。

## 二、激活函数的从零实现

在 4.1 节中我们证明了 ReLU 是现代深度学习中最优的非线性选择。其数学形式极其简洁：

$$\operatorname{ReLU}(x) = \max(x, 0)$$

我们基于 PyTorch 底层张量算子手动实现 `relu` 函数：

```python
def relu(X):
    a = torch.zeros_like(X)
    return torch.max(X, a)
```

### 运算机制说明：
1. `torch.zeros_like(X)`：在与输入张量 $X$ 相同的设备（CPU/GPU）上，创建一个形状完全一致、元素全为 0 的张量；
2. `torch.max(X, a)`：执行**逐元素比较（Element-wise Maxima）**。对于 $X$ 中的每一个标量分量 $x_{ij}$，若 $x_{ij} > 0$ 则保留原值，否则截断为 0。
3. 该操作在底层只调用底层向量化比较指令，没有涉及任何浮点指数 $\exp$ 或除法，吞吐极快。

---

## 三、定义模型架构与前向传播

网络的前向传播（Forward Pass）将输入图像经过平坦化、第一层线性投影、非线性激活，最后通过第二层线性投影输出未归一化的分类得分（Logits）。

```python
def net(X):
    # 1. 展平二维图像: (B, 1, 28, 28) -> (B, 784)
    X = X.reshape((-1, num_inputs))
    # 2. 隐藏层计算: H = relu(X @ W1 + b1)
    H = relu(X @ W1 + b1)  # 这里 "@" 表示矩阵乘法
    # 3. 输出层计算: O = H @ W2 + b2
    return (H @ W2 + b2)
```

### 张量维度与内存流转全景表

| 计算步骤 | 输入张量及形状 | 执行算子 | 输出张量及形状 | 数学含义 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 图像展平** | $X \in \mathbb{R}^{256 \times 1 \times 28 \times 28}$ | `reshape((-1, 784))` | $X \in \mathbb{R}^{256 \times 784}$ | 将 2D 空间图像像素展开为平坦特征向量 |
| **2. 隐藏层仿射变换** | $X \in \mathbb{R}^{256 \times 784}, W_1 \in \mathbb{R}^{784 \times 256}$ | `@` (矩阵乘法) + $b_1$ (广播) | $Z_1 \in \mathbb{R}^{256 \times 256}$ | 高维空间的第一层线性坐标变换 |
| **3. 非线性激活** | $Z_1 \in \mathbb{R}^{256 \times 256}$ | `relu(Z_1)` | $H \in \mathbb{R}^{256 \times 256}$ | 空间折叠，输出隐藏层特征表示 |
| **4. 输出层仿射变换** | $H \in \mathbb{R}^{256 \times 256}, W_2 \in \mathbb{R}^{256 \times 10}$ | `@` (矩阵乘法) + $b_2$ (广播) | $O \in \mathbb{R}^{256 \times 10}$ | 输出 10 个类别的未归一化得分 (Logits) |

> [!important] 为什么 `net(X)` 的末尾没有显式调用 `softmax`？
> 牢记 3.6 和 3.7 节推导出的 **LogSumExp 稳定性原则**：
> 如果在 `net` 内部调用 `softmax` 输出概率 $\hat{y}$，再送入交叉熵计算 $-\log(\hat{y})$，极易因浮点数精度限制触发严重的**数值下溢（$0.0 \to -\log(0) = \infty \to \text{NaN}$）**。
> 因此，现代框架的标准规范是：**网络前向只输出原始得分 $O$，Softmax 的指数归一化与其对数化简全部合并到后序的交叉熵损失函数中一次性安全完成！**

## 四、损失函数与优化器配置

由于我们在 3.6 节编写的训练框架 `d2l.train_ch3` 是完全通用的（它只依赖模型的前向输出与损失函数），我们直接复用该引擎：

```python
loss = nn.CrossEntropyLoss(reduction='none')
```

设置超参数并绑定优化器：
* 迭代周期数：`num_epochs = 10`
* 学习率：`lr = 0.1`
* 优化器：使用 PyTorch 内置的随机梯度下降 `torch.optim.SGD`，传入参数列表 `params = [W1, b1, W2, b2]`。

```python
num_epochs, lr = 10, 0.1
updater = torch.optim.SGD(params, lr=lr)
```

## 小结与核心提炼

> [!tip] 课程精髓提炼（融合李沐老师 `notebooks/208` 核心总结）

### 1. 从零实现的复杂度跃迁
* 手动实现单隐藏层 MLP 虽然直观，但参数管理量从单层模型的 2 个（$W, b$）翻倍到 4 个（$W_1, b_1, W_2, b_2$）。
* 随着网络深度进一步拓展（如 10 层甚至 50 层），手动初始化每一层权重并逐层编写命令式矩阵乘法将变得极其繁琐且极易出错，这就是为什么后续必须转向高级声明式 API（如 `nn.Sequential`）。

### 2. MLP 的性能上限与结构性短板
* 虽然 MLP 相比线性模型有了显著提升（$82.5\% \to 85.2\%$），但其提升幅度并未达到质变级别。
* **根本根源剖析（李沐老师核心要点）**：
  全连接多层感知机在输入端使用了 `X.reshape((-1, 784))`，**将二维图像强行打平成一维向量**。
  这种做法完全忽视了图像的**空间二维几何结构（Spatial Structure）**——相邻像素之间的纹理联系、边缘过渡和局部平移不变性被彻底丢弃。要实现计算机视觉准确率的革命性飞跃，必须借助后续第 6 章的**卷积神经网络（CNN）**。

## 练习

### 📌 练习 1：超参数 `num_hiddens` 的容量消融实验
> **问题**：尝试将 `num_hiddens` 的值分别设置为 32、64、128、256、512、1024，观察对收敛速度和测试集精度的影响。如何确定该超参数的最优值？

**深度理论与实验分析**：
1. **隐藏单元过少（`num_hiddens = 32` 或 `64`）—— 欠拟合（Underfitting）**：
   - 隐藏层特征维度过窄，形成“信息瓶颈（Information Bottleneck）”，模型无法将原本复杂的非线性流形映射到线性可分的高维空间；
   - 表现为训练损失下降缓慢，最终训练集准确率仅在 $82\% \sim 83\%$ 徘徊，测试集精度难以突破 $83\%$。
2. **隐藏单元适中（`num_hiddens = 128` 或 `256`）—— 黄金平衡点**：
   - 容量充足且参数量适中，测试集精度稳定达到 $85\% \sim 86\%$，泛化差距控制在合理范围。
3. **隐藏单元过大（`num_hiddens = 512` 或 `1024`）—— 边际效应递减与过拟合风险**：
   - 参数量呈几何倍数增加，前向与反向传播的矩阵乘法显存占用和算力消耗显著上升；
   - 训练集损失被进一步压缩到更低水平（如 $0.28$），但由于缺乏强正则化，测试集精度并未明显上涨（停留在约 $85.5\%$），泛化差距（Generalization Gap）显著拉大，过拟合风险攀升。
4. **最优超参数确定法则**：
   - 超参数无法通过反向传播自动求导更新，必须在**独立的验证集（Validation Set）**上进行网格搜索或贝叶斯优化，依据验证集误差的最低拐点确定最优容量。

### 📌 练习 2：增加隐藏层层数（深度的力量）
> **问题**：尝试添加更多的隐藏层（例如构建双隐藏层架构：$784 \to 256 \to 128 \to 10$），查看对结果有何影响？

**网络构建与代码实现**：
```python
# 双隐藏层参数初始化
W1 = nn.Parameter(torch.randn(784, 256, requires_grad=True) * 0.01)
b1 = nn.Parameter(torch.zeros(256, requires_grad=True))
W2 = nn.Parameter(torch.randn(256, 128, requires_grad=True) * 0.01)
b2 = nn.Parameter(torch.zeros(128, requires_grad=True))
W3 = nn.Parameter(torch.randn(128, 10, requires_grad=True) * 0.01)
b3 = nn.Parameter(torch.zeros(10, requires_grad=True))

def net_deep(X):
    X = X.reshape((-1, 784))
    H1 = relu(X @ W1 + b1)
    H2 = relu(H1 @ W2 + b2)
    return H2 @ W3 + b3
```

**实验机理剖析**：
1. **表达能力的层级抽象**：理论上，更深的网络能够实现**特征分层复用（Hierarchical Feature Reuse）**，第一层提取边缘线段，第二层组合出局部图案轮廓。
2. **优化难度与梯度传递**：
   - 增加一层导致反向传播链条多了一次矩阵乘法；
   - 若学习率仍设为 $0.1$，初期收敛速度可能略慢于单隐藏层网络；
   - 在 Fashion-MNIST 这种相对简单的低分辨率数据集上，双隐藏层最终测试精度通常提升至约 **$86.0\% \sim 86.5\%$**，但如果训练轮次过长，没有权重衰减等正则化配合，很容易出现过拟合。

### 📌 练习 3：学习率 $\eta$ 的敏感度分析
> **问题**：改变学习率对结果有何影响？保持模型架构不变，学习率设置为多少会获得更好的结果？

**数学推导与实验结论**：
* 参数沿负梯度方向更新：$\mathbf{w}_{t+1} = \mathbf{w}_t - \eta \nabla L$。
  * **$\eta = 0.01$（过小）**：步长极其微小，在有限的 10 个 Epoch 内模型犹如蜗牛爬行，远未到达损失曲面的极小值盆地，处于严重的欠收敛状态（Test Acc 约 $78\%$）；
  * **$\eta = 0.1 \sim 0.3$（最优区间）**：步长适中，每一步都能有效降低经验损失，曲线平滑下跌，在第 7~10 轮达到稳定收敛；
  * **$\eta = 1.0$（偏大）**：单步跨度过大，在损失曲面的狭长峡谷中来回剧烈震荡，损失下降停滞不前；
  * **$\eta \ge 5.0$（发散）**：步长直接跳出极值吸引域，引发数值溢出发散（Loss 变成 `inf` 或 `NaN`）。

### 📌 练习 4：联合超参数优化与经验最佳配置
> **问题**：同时调整学习率、隐藏层数、每层隐藏单元数，你能达到的最佳测试精度是多少？

**实测经验基准**：
* 在不引入卷积算子的前提下，全连接多层感知机在 Fashion-MNIST 上的理论上限约为 **$87.5\% \sim 88.0\%$**。
* **推荐冠军配置**：
  * 架构：双隐藏层（$784 \to 256 \to 128 \to 10$）
  * 激活函数：ReLU
  * 学习率：$\eta = 0.2$
  * 批量大小：$B = 256$
  * 训练轮数：$20$ 轮
  * 辅助正则化：在更新器中加入微小的权重衰减（`weight_decay = 1e-4`），最终可稳定斩获 **$87.8\%$** 的高精度。

### 📌 练习 5：为什么联合优化超参数极具挑战性？
> **问题**：为什么联合优化所有超参数涉及更具挑战性的策略？

**系统理论剖析**：
1. **超参数空间的维度灾难（Curse of Dimensionality）**：
   设我们有 $M$ 个超参数（如层数、每层神经元数、学习率、批量大小、权重衰减系数），若每个超参数仅采样 5 个离散值，则候选超参数组合总数高达 $5^M$（当 $M=5$ 时为 3125 种组合）。全空间网格搜索的算力开销是不可承受的。
2. **强烈的非凸非线性耦合效应（Coupling Effect）**：
   超参数之间不是相互独立的。例如：
   * 改变批量大小 $B$ 必须联动改变学习率 $\eta$（线性缩放法则：$B \times k \implies \eta \times k$）；
   * 增加网络深度往往必须联动降低初始方差或引入更强的正则化。
   * 单独调优某一个超参数找到的“最优值”，在另一个超参数发生微调后会彻底失效。
3. **黑盒评估成本高昂（Expensive Black-box Function）**：
   超参数的目标函数是“模型经过完整多轮训练后的验证集性能”，单次评估需要耗费数分钟乃至数小时的硬件算力，且无法通过梯度自动求导。

### 📌 练习 6：工业级 AutoML 自动化调优框架的必备组件
> **问题**：如果要构建一个通用的超参数自动化调优策略，它应该包含哪些核心组件？

**工业级 AutoML（如 Optuna、Ray Tune）核心架构组件**：
1. **搜索空间配置器（Search Space Definition）**：
   定义每个超参数的先验分布形态（如学习率通常在对数空间均匀采样 `loguniform(1e-4, 1e-1)`，隐藏单元数在整型空间采样 `choice([64, 128, 256, 512])`）；
2. **采样建议算法引擎（Sampling Algorithm / Suggester）**：
   - 随机采样（Random Search）：相比穷举网格搜索，随机搜索能以极少试验覆盖更高维度的重要参数；
   - 贝叶斯优化（Bayesian Optimization / TPE）：利用高斯过程或 Parzen 窗估计参数与验证指标的映射关系，动态平衡“探索未知（Exploration）”与“利用已知（Exploitation）”；
3. **早停与剪枝调度器（Early Stopping & Pruner）**：
   - 基于 **Hyperband** 或 **ASHA（Asynchronous Successive Halving Algorithm）** 算法；
   - 在试验初期（例如前 3 个 Epoch）评估当前配置的收敛斜率，一旦发现处于后 $50\%$ 的不良表现，立即强制杀死该任务，将算力资源腾挪给有潜力的优质参数组合；
4. **隔离评估与实验追踪面板（Objective Evaluator & Tracker）**：
   在纯净的验证集上无偏统计多轮交叉验证指标，并可视化参数相关性雷达图。
