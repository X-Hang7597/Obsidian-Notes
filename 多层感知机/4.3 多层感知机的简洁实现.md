# 多层感知机的简洁实现

正如我们在 [[3.3 线性回归的简洁实现|3.3 节]] 与 [[3.7 softmax回归的简洁实现|3.7 节]] 中所见，深度学习框架的高阶 API（`torch.nn`）能够极大地减少样板代码，使我们能够聚焦于**模型拓扑架构**与**训练超参数设计**。

本节我们将使用 PyTorch 高级 API 实现包含一个隐藏层的多层感知机。

```python
import torch
from torch import nn
from d2l import torch as d2l
```

---

## 一、定义模型架构与参数初始化

对比 3.7 节的 Softmax 回归，多层感知机唯一的区别是在全连接层之间**插入了隐藏层与非线性激活层**。

```python
net = nn.Sequential(
    nn.Flatten(),               # 将 (B, 1, 28, 28) 展平为 (B, 784)
    nn.Linear(784, 256),        # 隐藏层：784 -> 256
    nn.ReLU(),                  # 逐元素激活函数
    nn.Linear(256, 10)          # 输出层：256 -> 10 (输出 logits)
)

def init_weights(m):
    if type(m) == nn.Linear:
        nn.init.normal_(m.weight, std=0.01)

net.apply(init_weights);
```

### 架构细节剖析：
1. **`nn.Flatten()`**：保留第 0 维（批大小 $B$），将后序多维空间维度拉平为单个一维特征向量；
2. **`nn.ReLU()`**：作为独立的网络层嵌入 `nn.Sequential` 中，负责在隐藏层输出上执行无参数的逐元素非线性变换；
3. **`net.apply(init_weights)`**：递归遍历所有子模块，精准识别出其中的 `nn.Linear` 线性层，并将其权重矩阵原地初始化为均值 0、标准差 0.01 的高斯正态分布（偏置默认为 0）。

---

## 二、训练与评估

训练逻辑与 Softmax 回归的简洁实现完全相同。PyTorch 框架的模块化设计确保了优化器与损失函数能够无缝适配不同的网络架构。

```python
batch_size, lr, num_epochs = 256, 0.1, 10
loss = nn.CrossEntropyLoss(reduction='none')
trainer = torch.optim.SGD(net.parameters(), lr=lr)

train_iter, test_iter = d2l.load_data_fashion_mnist(batch_size)
d2l.train_ch3(net, train_iter, test_iter, loss, num_epochs, trainer)
```

## 三、从零实现 vs 简洁实现核心维度对照

| 维度 | 4.2 从零开始实现 | 4.3 简洁实现（PyTorch API） |
| :--- | :--- | :--- |
| **张量展平** | `X.reshape((-1, num_inputs))` | **`nn.Flatten()`** |
| **网络定义** | 手写函数 `net(X)`，显式矩阵乘法 `@` 与加法 | **`nn.Sequential` 声明式流水线** |
| **参数维护** | 显式声明 `[W1, b1, W2, b2]` 列表 | **`net.parameters()` 自动参数注册与管理** |
| **激活函数** | 手写 `torch.max(X, zeros)` | **`nn.ReLU()` 框架内置高效算子** |
| **权重初始化** | 手动乘 `0.01` 并设 `requires_grad=True` | **`net.apply(init_weights)` 遍历初始化** |

## 小结与核心提炼

> [!tip] 课程精髓提炼（融合李沐老师 `notebooks/208` 核心总结）

* **声明式编程的工业价值**：通过 `nn.Sequential`，网络拓扑从命令式的矩阵乘法运算转变为**可插拔的模块堆叠**。无论是修改隐藏层宽度、改变激活函数类型，还是追加深层网络，只需增加一行代码，无需重写任何前向计算函数。
* **参数绑定的自动化**：优化器只需接收 `net.parameters()`，框架自动完成所有深层子模块参数及其梯度的追踪与绑定，彻底消除了手动维护参数列表的易错性。

## 练习

### 📌 练习 1：多隐藏层的层级设计实验
> **问题**：尝试添加不同的隐藏层（并微调学习率），查看对收敛效果有何影响？

**深度解析**：
* 构建更深的阶梯式架构：
  ```python
  net = nn.Sequential(
      nn.Flatten(),
      nn.Linear(784, 256),
      nn.ReLU(),
      nn.Linear(256, 128),
      nn.ReLU(),
      nn.Linear(128, 64),
      nn.ReLU(),
      nn.Linear(64, 10)
  )
  ```
* **实验观察与规律**：
  1. 层数加深时，每个参数的梯度回传路径更长，初期收敛速度可能变缓，往往需要微调学习率（如将 $0.1$ 调至 $0.15$ 或引入带动量的优化器）；
  2. 针对 $28 \times 28$ 这种低分辨率图像，堆叠超过 3 层全连接层会迅速出现边际效用递减，不仅精度无法进一步提升，而且更容易产生过拟合。

---

### 📌 练习 2：激活函数的横向对比
> **问题**：尝试将 `nn.ReLU()` 替换为不同的激活函数（如 `nn.Sigmoid()`、`nn.Tanh()`、`nn.LeakyReLU()`），哪个效果更好？为什么？

**实测机理分析**：
1. **`nn.ReLU()` 与 `nn.LeakyReLU()` 表现最优**：
   - 训练收敛速度最快，10 个 Epoch 即可稳定收敛至约 $85\%$ 准确率；
   - 正半轴不饱和特性保证了梯度在反向传播时无衰减回传。
2. **`nn.Tanh()` 次之**：
   - 凭借零中心化优势，收敛速度相对可观，但由于两端饱和区梯度趋近于 0，在相同学习率下收敛斜率略逊于 ReLU。
3. **`nn.Sigmoid()` 表现最差**：
   - 极易陷入梯度消失，前向输出均值偏移破坏了优化平稳性，前几个 Epoch 损失下降极其缓慢，最终精度显著落后。

---

### 📌 练习 3：不同权重初始化方法的威力
> **问题**：尝试不同的权重初始化方法（如全零初始化、标准正态分布、Xavier 初始化），会观察到什么现象？

**理论与实测解析**：
1. **全零初始化（`nn.init.zeros_(m.weight)`）—— 致命对称性破坏**：
   - 隐藏层中所有神经元的权重全为 0，导致前向输出完全一致，反向传播时每个隐藏神经元收到的梯度完全相同；
   - 所有神经元陷入“同生同灭”的对称性，多隐藏单元退化为单一神经元，模型彻底丧失拟合能力。
2. **标准正态分布（`std=1.0` 未缩放）—— 数值爆炸**：
   - 初始权重方差过大，矩阵相乘导致隐藏层激活值迅速发散到极大数值，使后续层发生上溢或饱和，训练崩溃。
3. **Xavier 均匀/正态初始化（`nn.init.xavier_uniform_(m.weight)`）—— 工业标准**：
   - 根据输入输出维度自动确定初始方差（$\sigma^2 = \frac{2}{\text{in} + \text{out}}$），前向激活值与反向梯度的方差在各层之间保持稳定，初始收敛极度顺畅平稳（将在 4.8 节展开严格数学推导）。
