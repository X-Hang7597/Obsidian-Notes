# 权重衰减（Weight Decay / $L_2$ 正则化）

在上一节中，我们看到当模型参数量过多而训练数据稀缺时，模型会疯狂利用高阶自由度去死记硬背噪声，产生严重的过拟合。

解决过拟合最直接的数学方案之一，就是在目标函数中对参数的复杂度进行**显式惩罚**。这种技术在统计学中被称为**岭回归（Ridge Regression）**，在深度学习领域则被普遍称为**权重衰减（Weight Decay）**或 **$L_2$ 正则化**。

```python
%matplotlib inline
import torch
from torch import nn
from d2l import torch as d2l
```

---

## 一、数学机理与参数收缩推导

### 1. 连续性、平滑性与权重范数
直观上，一个复杂且过拟合的函数往往会在极小的输入变动下产生剧烈的输出震荡（高阶导数极大）。
对于线性模型 $f(\mathbf{x}) = \mathbf{w}^\top \mathbf{x} + b$，若输入特征发生微小扰动 $\boldsymbol{\epsilon}$，输出的变化量为：
$$
|f(\mathbf{x} + \boldsymbol{\epsilon}) - f(\mathbf{x})| = |\mathbf{w}^\top \boldsymbol{\epsilon}| \le \|\mathbf{w}\|_2 \|\boldsymbol{\epsilon}\|_2
$$
**柯西-施瓦茨不等式告诉我们：权重的 $L_2$ 范数 $\|\mathbf{w}\|_2$ 直接充当了函数李普希茨常数（Lipschitz Constant）的上界！** 权重越小，函数越平滑，对噪声和扰动越鲁棒。

### 2. 目标函数构建
为了限制参数范数，我们在原有的经验损失函数后加上 $L_2$ 范数惩罚项：
$$
L_{\text{reg}}(\mathbf{w}, b) = L(\mathbf{w}, b) + \frac{\lambda}{2} \|\mathbf{w}\|_2^2
$$
* $\lambda \ge 0$ 为**正则化超参数**：
  * 若 $\lambda = 0$：退化为无正则化的标准经验损失；
  * 若 $\lambda \to +\infty$：强迫所有权重 $\mathbf{w} \to \mathbf{0}$；
* **为什么除以 2？** 便于在求导时与平方项展开的常数 2 相互抵消。
* **为什么通常不惩罚偏置 $b$？** 偏置只负责控制决策平面的全局平移，并不控制函数的曲率或敏感度。惩罚偏置不仅无助于防过拟合，反而容易造成欠拟合。

### 3. “权重衰减”名称的代数起源（参数收缩算子）
我们对带正则化的损失函数关于 $\mathbf{w}$ 求梯度：
$$
\frac{\partial L_{\text{reg}}}{\partial \mathbf{w}} = \frac{\partial L}{\partial \mathbf{w}} + \lambda \mathbf{w}
$$
采用小批量随机梯度下降更新参数：
$$
\begin{aligned}
\mathbf{w}_{t+1} &= \mathbf{w}_t - \eta \left( \frac{\partial L}{\partial \mathbf{w}_t} + \lambda \mathbf{w}_t \right) \\
&= \mathbf{w}_t - \eta \lambda \mathbf{w}_t - \eta \frac{\partial L}{\partial \mathbf{w}_t} \\
&= \mathbf{(1 - \eta \lambda) \mathbf{w}_t} - \eta \frac{\partial L}{\partial \mathbf{w}_t}
\end{aligned}
$$

> [!important] 核心代数洞见：为什么叫“权重衰减”？
> 注意公式中的 **$(1 - \eta \lambda)$** 项！
> 通常学习率 $\eta$ 和正则项 $\lambda$ 都是较小的正数，满足 $\eta \lambda < 1$，故 $(1 - \eta \lambda) \in (0, 1)$。
> 这意味着：**在每一步根据样本误差梯度更新之前，模型都会首先将上一轮的权重按比例“缩小（衰减）”一点点！**

## 二、高维过拟合实验设置

为了清晰观察权重衰减的抑制效果，我们人为构造一个**严重缺乏数据的高维病态问题**：
* 样本数量极少：`n_train = 20`（仅 20 个训练样本）
* 特征维度极高：`num_inputs = 200`（200 个特征）
* 标签生成机制：$y = 0.05 + \sum_{i=1}^{200} 0.01 x_i + \epsilon, \quad \epsilon \sim \mathcal{N}(0, 0.01^2)$

在样本数远小于参数量（$n \ll d$）的极端情况下，模型极易产生毁灭性的过拟合。

```python
n_train, n_test, num_inputs, batch_size = 20, 100, 200, 5
true_w, true_b = torch.ones((num_inputs, 1)) * 0.01, 0.05
train_data = d2l.synthetic_data(true_w, true_b, n_train)
train_iter = d2l.load_array(train_data, batch_size)
test_data = d2l.synthetic_data(true_w, true_b, n_test)
test_iter = d2l.load_array(test_data, batch_size, is_train=False)
```

---

## 三、从零开始实现权重衰减

### 1. 初始化模型参数与手写惩罚项

```python
def init_params():
    w = torch.normal(0, 1, size=(num_inputs, 1), requires_grad=True)
    b = torch.zeros(1, requires_grad=True)
    return [w, b]

def l2_penalty(w):
    return torch.sum(w.pow(2)) / 2
```

### 2. 训练与效果对比

```python
def train_scratch(lambd):
    w, b = init_params()
    net, loss = lambda X: d2l.linreg(X, w, b), d2l.squared_loss
    num_epochs, lr = 100, 0.003
    animator = d2l.Animator(xlabel='epochs', ylabel='loss', yscale='log',
                            xlim=[5, num_epochs], legend=['train', 'test'])
    for epoch in range(num_epochs):
        for X, y in train_iter:
            # 增加了 L2 范数惩罚项
            l = loss(net(X), y) + lambd * l2_penalty(w)
            l.sum().backward()
            d2l.sgd([w, b], lr, batch_size)
        if (epoch + 1) % 5 == 0:
            animator.add(epoch + 1, (d2l.evaluate_loss(net, train_iter, loss),
                                     d2l.evaluate_loss(net, test_iter, loss)))
    print('w的L2范数是：', torch.norm(w).item())
```

#### 对比 A：忽略权重衰减（`lambd = 0`）
```python
train_scratch(lambd=0)
```
* **运行现象**：训练损失趋向于 0，但测试损失反弹至数倍乃至数十倍，`w` 的 $L_2$ 范数暴增到 **13.5** 左右。模型完全被随机噪声带跑。

#### 对比 B：启用权重衰减（`lambd = 3`）
```python
train_scratch(lambd=3)
```
* **运行现象**：训练损失适度上升，但测试损失得到极其有效的控制，大幅下跌；`w` 的 $L_2$ 范数被强制压制在 **0.3** 左右，模型学到了真正有泛化价值的平滑边界。

## 四、简洁实现（PyTorch `weight_decay` API）

在工业级深度学习中，我们无需在损失函数后面手动写 `+ lambd * l2_penalty(w)`，PyTorch 的优化器原生支持了 `weight_decay` 参数。

> [!important] 工业级避坑指南：权重与偏置的分组衰减
> 正如理论推导，我们**只应对权重矩阵施加衰减，而偏置应设置 `weight_decay=0`**。在 PyTorch 中通过参数字典实现差异化配置：

```python
def train_concise(wd):
    net = nn.Sequential(nn.Linear(num_inputs, 1))
    for param in net.parameters():
        param.data.normal_()
    loss = nn.MSELoss(reduction='none')
    num_epochs, lr = 100, 0.003
    
    # 精准分组：权重衰减 vs 偏置不衰减
    trainer = torch.optim.SGD([
        {"params": net[0].weight, 'weight_decay': wd},
        {"params": net[0].bias}  # bias 默认 weight_decay=0
    ], lr=lr)
    
    animator = d2l.Animator(xlabel='epochs', ylabel='loss', yscale='log',
                            xlim=[5, num_epochs], legend=['train', 'test'])
    for epoch in range(num_epochs):
        for X, y in train_iter:
            trainer.zero_grad()
            l = loss(net(X), y)
            l.mean().backward()
            trainer.step()
        if (epoch + 1) % 5 == 0:
            animator.add(epoch + 1, (d2l.evaluate_loss(net, train_iter, loss),
                                     d2l.evaluate_loss(net, test_iter, loss)))
    print('w的L2范数：', net[0].weight.norm().item())
```

## 小结与核心提炼

> [!tip] 课程精髓提炼（融合李沐老师 `notebooks/210` 核心总结）

* **拉格朗日对偶的软约束**：权重衰减在数学上等价于带有硬球约束的最优化问题（$\min L(\mathbf{w})$ 使得 $\|\mathbf{w}\|_2^2 \le \theta$）。拉格朗日乘子 $\lambda$ 充当了调节球体半径的“软旋钮”。
* **参数收缩的本质**：$(1 - \eta \lambda)$ 保证了参数在每一次迭代中都被持续拉向原点，只有当梯度的推动力足够强且持续时，参数才能在原点外维持平衡。
* **分层差异化正则**：在更复杂的现代网络中，不仅偏置不衰减，Normalization 层（如 BatchNorm/LayerNorm）的缩放与平移系数 $\gamma, \beta$ 通常也强制设为 `weight_decay=0`。

## 练习

### 📌 练习 1：正则化系数 $\lambda$ 的调优轨迹
> **问题**：在上述高维回归实验中尝试不同的 $\lambda$ 值，观察训练和测试误差的变化。

**深度解析**：
* 当 $\lambda$ 从 $0$ 逐步增加到 $10$：
  * **$\lambda = 0$（无约束）**：严重过拟合，泛化差距极大；
  * **$\lambda = 0.5 \sim 3$（最优区间）**：训练损失略有上升，但测试损失大幅下降，泛化差距缩减至最小；
  * **$\lambda \ge 10$（过度约束）**：权重被强行压缩至趋近于 0，模型丧失了表达能力，退化为欠拟合状态，训练与测试误差均急剧恶化。

---

### 📌 练习 2：利用验证集选择最佳 $\lambda$
> **问题**：如何使用独立的验证集确定超参数 $\lambda$ 的最佳取值？

**标准工程流程**：
1. 设定候选 $\lambda$ 的对数等比网格，例如 $\Lambda = \{10^{-4}, 10^{-3}, 10^{-2}, 10^{-1}, 1, 10\}$；
2. 在固定训练集上训练，在固定验证集上评估 MSE 损失；
3. 绘制 $\lambda \to \text{Loss}_{\text{val}}$ 曲线，挑选处于“U型谷底”极小值点对应的 $\lambda^*$ 作为最终模型超参数。

---

### 📌 练习 3：$L_1$ 正则化（Lasso）的更新方程与稀疏性
> **问题**：如果改用 $L_1$ 正则化（$\frac{\lambda}{2} \sum_i |w_i|$ 或 $\lambda \|\mathbf{w}\|_1$），参数更新方程会变成什么样？

**代数推导与几何对比**：
设损失函数为 $L_{\text{L1}} = L(\mathbf{w}) + \lambda \sum_{i} |w_i|$。
对 $w_i$ 求偏导（除 $w_i = 0$ 外）：
$$
\frac{\partial L_{\text{L1}}}{\partial w_i} = \frac{\partial L}{\partial w_i} + \lambda \operatorname{sign}(w_i)
$$
采用 SGD 更新：
$$
w_{i, t+1} = w_{i, t} - \eta \frac{\partial L}{\partial w_{i, t}} - \mathbf{\eta \lambda \operatorname{sign}(w_{i, t})}
$$
**核心差异解析**：
* **$L_2$ 衰减**：惩罚项为 $\eta \lambda w_i$，参数绝对值越大惩罚越猛，参数接近 0 时惩罚极小，因此参数只会被无限压缩而**不会精确等于 0**；
* **$L_1$ 衰减**：惩罚项为常数步长 $\eta \lambda \operatorname{sign}(w_i)$，无论参数多小，每一步都以恒定步长向 0 扣减，能够直接将非显著参数**强行截断为精确的 0**，因此 $L_1$ 具备天然的**特征选择与稀疏化（Sparsity）**能力。

---

### 📌 练习 4：矩阵参数的 Frobenius 范数
> **问题**：对于全连接层的权重矩阵 $\mathbf{W} \in \mathbb{R}^{d \times q}$，它的 $L_2$ 范数在代数上是如何定义的？

**解答**：
对于二维矩阵，向量的 $L_2$ 范数自然推广为 **Frobenius 范数（记作 $\|\mathbf{W}\|_F$）**：
$$
\|\mathbf{W}\|_F = \sqrt{\sum_{i=1}^d \sum_{j=1}^q W_{ij}^2} = \sqrt{\operatorname{tr}(\mathbf{W}^\top \mathbf{W})}
$$
其平方形式正是矩阵所有元素平方的简单双重累加和，其梯度依然是 $\frac{\partial}{\partial \mathbf{W}} \left( \frac{1}{2}\|\mathbf{W}\|_F^2 \right) = \mathbf{W}$，形式保持严密的简洁一致性。

---

### 📌 练习 5：数据量与权重衰减的替代效应
> **问题**：如果无限增加训练数据量，对权重衰减的需求会发生什么变化？

**解答**：
随着样本量 $n \to \infty$，根据大数定律，经验风险 $R_{\text{emp}}(\mathbf{w})$ 严格一致收敛于真实期望风险 $R_{\text{exp}}(\mathbf{w})$。
海量数据本身对高阶参数形成了极强的刚性约束，噪声的相对比例趋近于 0，模型不再有“死记硬背”的空间。因此，**数据量越庞大，对权重衰减等显式正则化的依赖程度就越低**。

---

### 📌 练习 6：贝叶斯统计视角下的最大后验估计（MAP）
> **问题**：在贝叶斯统计中，利用后验概率 $P(\mathbf{w} \mid \mathbf{y}) \propto P(\mathbf{y} \mid \mathbf{w}) P(\mathbf{w})$，如何从理论上导出权重衰减？

**严密统计学推导**：
1. **似然项（数据生成假设）**：假设误差服从高斯分布 $\epsilon \sim \mathcal{N}(0, \sigma^2)$，则样本似然为：
   $$
   P(\mathbf{y} \mid \mathbf{X}, \mathbf{w}) = \prod_{i=1}^n \frac{1}{\sqrt{2\pi}\sigma} \exp\left( -\frac{(y_i - \mathbf{w}^\top \mathbf{x}_i)^2}{2\sigma^2} \right)
   $$
2. **先验项（参数先验假设）**：假设我们在未看到任何数据前，先验认为权重偏向于保持在 0 附近，服从**零均值高斯先验（Gaussian Prior）** $\mathbf{w} \sim \mathcal{N}(\mathbf{0}, \sigma_0^2 \mathbf{I})$：
   $$
   P(\mathbf{w}) = \frac{1}{(2\pi)^{d/2} \sigma_0^d} \exp\left( -\frac{\|\mathbf{w}\|_2^2}{2\sigma_0^2} \right)
   $$
3. **最大后验估计（MAP）与负对数后验**：
   $$
   \begin{aligned}
   \max_{\mathbf{w}} \log P(\mathbf{w} \mid \mathbf{y}) &= \max_{\mathbf{w}} \left[ \log P(\mathbf{y} \mid \mathbf{w}) + \log P(\mathbf{w}) \right] \\
   &= \min_{\mathbf{w}} \left[ \frac{1}{2\sigma^2} \sum_{i=1}^n (y_i - \mathbf{w}^\top \mathbf{x}_i)^2 + \frac{1}{2\sigma_0^2} \|\mathbf{w}\|_2^2 \right]
   \end{aligned}
   $$
两边同时乘以 $\sigma^2$：
$$
\min_{\mathbf{w}} \left[ \frac{1}{2} \sum_{i=1}^n (y_i - \mathbf{w}^\top \mathbf{x}_i)^2 + \frac{\sigma^2}{2\sigma_0^2} \|\mathbf{w}\|_2^2 \right]
$$
令超参数 $\lambda = \frac{\sigma^2}{\sigma_0^2}$，该式**严格等价于带有 $L_2$ 正则化的平方损失函数！**
**结论**：**权重衰减在贝叶斯学派眼中，完全等价于假定模型参数服从零均值高斯先验分布的最大后验估计。**
