# 实战 Kaggle 比赛：预测房价（Ames Housing）

到目前为止，我们一直在使用经过高度清洗的学术玩具数据集（如合成线性数据或裁剪居中的 Fashion-MNIST）。然而在真实工业世界中，数据往往是**脏乱差**的——存在海量特征缺失、离散分类变量与连续数值混合、跨数量级尺度差异。

本节我们将进入真正的竞技赛场——**Kaggle 经典竞赛：爱荷华州埃姆斯（Ames）房价预测**。我们将完整打通工业级机器学习端到端闭环：**数据清洗与特征工程 $\to$ 对数评估指标构建 $\to$ 多层感知机建模 $\to$ $K$ 折交叉验证超参搜索 $\to$ 生成打榜提交文件**。

## 一、数据集下载与结构探索

比赛数据集包含 1460 个训练样本和 1460 个测试样本，每个样本包含 79 个房屋描述特征（如建造年份、屋顶类型、地下室状况、地段面积等）以及房屋标识符 `Id`。

```python
# 数据下载缓存机制
DATA_HUB = dict()
DATA_URL = 'http://d2l-data.s3-accelerate.amazonaws.com/'

def download(name, cache_dir=os.path.join('..', 'data')):
    assert name in DATA_HUB, f"{name} 不存在于 DATA_HUB"
    url, sha1_hash = DATA_HUB[name]
    os.makedirs(cache_dir, exist_ok=True)
    fname = os.path.join(cache_dir, url.split('/')[-1])
    if os.path.exists(fname):
        sha1 = hashlib.sha1()
        with open(fname, 'rb') as f:
            while True:
                data = f.read(1048576)
                if not data:
                    break
                sha1.update(data)
        if sha1.hexdigest() == sha1_hash:
            return fname
    print(f'正在从 {url} 下载 {fname}...')
    r = requests.get(url, stream=True, verify=True)
    with open(fname, 'wb') as f:
        f.write(r.content)
    return fname

DATA_HUB['kaggle_house_train'] = (DATA_URL + 'kaggle_house_pred_train.csv',
                                   '585e9ccff0470b4460e690edd38233c473063ec8')
DATA_HUB['kaggle_house_test'] = (DATA_URL + 'kaggle_house_pred_test.csv',

train_data = pd.read_csv(download('kaggle_house_train'))

```

## 二、工业级特征工程（Feature Engineering）

> [!important] 工业界共识：特征工程决定上限，模型调优只是逼近上限
> 表格结构化数据（Tabular Data）的核心胜负手在于特征预处理。

### 1. 连续数值特征：Z-Score 标准化与均值填补
不同特征的物理量纲差异极大（如建造年份在 $1900 \sim 2010$，而卧室数量在 $1 \sim 5$）。我们通过标准化将所有数值特征变换为均值为 0、方差为 1 的标准尺度：
$$
x \leftarrow \frac{x - \mu}{\sigma}
$$
标准化之后，**缺失值（NaN）可以直接填补为 0（即该特征的均值 $\mu$）**：

```python
# 筛选所有数值类型的特征列
numeric_features = all_features.dtypes[all_features.dtypes != 'object'].index

# Z-score 标准化
all_features[numeric_features] = all_features[numeric_features].apply(
    lambda x: (x - x.mean()) / (x.std()))

# 标准化后，均值为 0，缺失值直接填补为 0
all_features[numeric_features] = all_features[numeric_features].fillna(0)
```

### 2. 离散类别特征：One-Hot 独热编码
对于离散无序字符串（如 `MSZoning` 包含 `['RL', 'RM', 'C']` 等分类）：
* 必须将其展开为二元指示向量（One-Hot）；
* **缺失值本身往往也是一个独立信号**（例如没有地下室的房屋，地下室类型字段缺失）。我们将 `dummy_na=True`，让缺失值单独构成一个类别维度。

```python
all_features = pd.get_dummies(all_features, dummy_na=True)
print(all_features.shape)  # 特征维度从 79 激增至 331 维！
```

将处理完毕的 Pandas DataFrame 转换为 PyTorch 张量：
```python
n_train = train_data.shape[0]
train_features = torch.tensor(all_features[:n_train].values.astype(float), dtype=torch.float32)
test_features = torch.tensor(all_features[n_train:].values.astype(float), dtype=torch.float32)
train_labels = torch.tensor(train_data.SalePrice.values.reshape(-1, 1), dtype=torch.float32)
```

## 三、对数评估指标（Log-RMSE）构建

在评估房屋售价时，**绝对误差是不公平的**：
* 豪宅售价 2,000,000 美元，预测为 2,100,000 美元，绝对误差为 100,000 美元（误差比例仅为 $5\%$）；
* 平房售价 100,000 美元，预测为 200,000 美元，绝对误差也是 100,000 美元（误差比例高达 $100\%$）。

如果直接优化均方根误差（RMSE），模型会过度偏向拟合极少数昂贵豪宅。因此，Kaggle 官方规定采用**对数均方根误差（Log-RMSE）**作为天梯榜衡量标准：

$$\text{Log-RMSE} = \sqrt{\frac{1}{n} \sum_{i=1}^n \left( \log y_i - \log \hat{y}_i \right)^2}$$

由于 $\log y - \log \hat{y} = \log\left(\frac{y}{\hat{y}}\right)$，该指标**本质上衡量的是预测值与真实值之间的相对比率误差**。

```python
loss = nn.MSELoss()

def log_rmse(net, features, labels):
    # 将小于 1 的预测值截断为 1，防止对数计算崩溃
    clipped_preds = torch.clamp(net(features), 1, float('inf'))
    rmse = torch.sqrt(loss(torch.log(clipped_preds), torch.log(labels)))
    return rmse.item()
```

## 四、模型构建与 $K$ 折交叉验证流程

我们既可以选用单层线性回归作为 Baseline，也可以采用两层多层感知机（MLP）：

```python
in_features = train_features.shape[1]

def get_net():
    # 单隐藏层 MLP 架构
    net = nn.Sequential(
        nn.Linear(in_features, 128),
        nn.ReLU(),
        nn.Dropout(0.2),
        nn.Linear(128, 1)
    )
    return net
```

### 1. 单轮训练函数
```python
def train(net, train_features, train_labels, test_features, test_labels,
          num_epochs, learning_rate, weight_decay, batch_size):
    train_ls, test_ls = [], []
    train_iter = d2l.load_array((train_features, train_labels), batch_size)
    optimizer = torch.optim.Adam(net.parameters(), lr=learning_rate, weight_decay=weight_decay)
    
    for epoch in range(num_epochs):
        for X, y in train_iter:
            optimizer.zero_grad()
            l = loss(net(X), y)
            l.backward()
            optimizer.step()
        train_ls.append(log_rmse(net, train_features, train_labels))
        if test_labels is not None:
            test_ls.append(log_rmse(net, test_features, test_labels))
    return train_ls, test_ls
```

### 2. $K$ 折数据切分与交叉验证统筹
```python
def get_k_fold_data(k, i, X, y):
    assert k > 1
    fold_size = X.shape[0] // k
    X_train, y_train = None, None
    for j in range(k):
        idx = slice(j * fold_size, (j + 1) * fold_size)
        X_part, y_part = X[idx, :], y[idx]
        if j == i:
            X_valid, y_valid = X_part, y_part
        elif X_train is None:
            X_train, y_train = X_part, y_part
        else:
            X_train = torch.cat([X_train, X_part], 0)
            y_train = torch.cat([y_train, y_part], 0)
    return X_train, y_train, X_valid, y_valid

def k_fold(k, X_train, y_train, num_epochs, learning_rate, weight_decay, batch_size):
    train_l_sum, valid_l_sum = 0, 0
    for i in range(k):
        data = get_k_fold_data(k, i, X_train, y_train)
        net = get_net()
        train_ls, valid_ls = train(net, *data, num_epochs, learning_rate,
                                   weight_decay, batch_size)
        train_l_sum += train_ls[-1]
        valid_l_sum += valid_ls[-1]
        print(f'折 {i + 1}，训练log rmse: {float(train_ls[-1]):f}, 验证log rmse: {float(valid_ls[-1]):f}')
    return train_l_sum / k, valid_l_sum / k
```

## 五、超参数调优与生成提交文件

```python
k, num_epochs, lr, weight_decay, batch_size = 5, 100, 5, 0, 64
train_l, valid_l = k_fold(k, train_features, train_labels, num_epochs, lr,
```

在 5 折验证集指标收敛至满意水平后（通常在 $0.14 \sim 0.16$ 左右），我们利用**全部训练集全量数据**重新训练一个最终模型，并导出标准格式的 `submission.csv`：

```python
def train_and_pred(train_features, test_features, train_labels, test_data,
                   num_epochs, lr, weight_decay, batch_size):
    net = get_net()
    train_ls, _ = train(net, train_features, train_labels, None, None,
                        num_epochs, lr, weight_decay, batch_size)
    print(f'全量训练log rmse: {float(train_ls[-1]):f}')
    
    # 在未知测试集上进行推断
    preds = net(test_features).detach().numpy()
    
    # 格式化导出为符合 Kaggle 提交标准的 CSV
    test_data['SalePrice'] = pd.Series(preds.reshape(1, -1)[0])
    submission = pd.concat([test_data['Id'], test_data['SalePrice']], axis=1)
    submission.to_csv('submission.csv', index=False)

train_and_pred(train_features, test_features, train_labels, test_data,
               num_epochs, lr, weight_decay, batch_size)
```

## 小结与核心提炼

> [!tip] 课程精髓提炼（融合李沐老师 `notebooks/213` 核心总结）

* **数据清洗的三板斧**：
  1. 缺失值填补：数值型标准化后填 0，离散型将缺失单独作为一列 One-Hot；
  2. 离散编码：`pd.get_dummies` 展开分类变量，消除字符串不可导障碍；
  3. 目标值分布变换：若目标值长尾偏态严重，对目标值直接取对数 $\log(y)$ 训练也是极其有效的技巧。
* **$K$ 折交叉验证的指导意义**：不要在测试集上盲目“碰运气”。唯有当本地 $K$ 折验证分数稳定提升时，线上测试集分数才具有稳固提升的保障。

## 练习

### 📌 练习 1：直接优化 Log-RMSE vs 目标值取对数训练
> **问题**：在训练阶段，直接使用均方误差 `nn.MSELoss(net(X), y)`，而在评估时计算 Log-RMSE；与在训练前直接令 `y_log = torch.log(y)`，训练目标直接设为 `nn.MSELoss(net(X), y_log)`，这两种方案有何本质差异？哪个更好？

**深度理论推导**：
1. **方案 A（本节做法：直接优化原始价格，评估算对数）**：
   - 损失函数为 $\frac{1}{2}(\hat{y} - y)^2$。求导梯度为 $\hat{y} - y$。
   - 梯度的绝对幅度被高价豪宅完全主导，百万豪宅的一个梯度步长相当于几十套平房，优化器在优化方向上极度偏向高价房，低价房相对被边缘化。
2. **方案 B（工业界标准做法：对目标值取对数 $\tilde{y} = \log y$）**：
   - 令模型直接预测对数价格 $\hat{z} = \text{net}(\mathbf{x}) \approx \log y$。
   - 训练损失设为：
     $$
     L = \frac{1}{2} (\hat{z} - \log y)^2 = \frac{1}{2} (\log \hat{y} - \log y)^2
     $$
   - 此时**训练损失的最小化目标在数学上精确等价于最小化 Log-RMSE！**
   - 梯度为 $\log \hat{y} - \log y \approx \frac{\hat{y} - y}{y}$（相对误差）。所有价格区间的房屋获得了完全平等的相对梯度权重，收敛速度与最终排名指标**显著优于方案 A**。

---

### 📌 练习 2：特征工程深入 —— 缺失值不仅仅是平均值
> **问题**：将缺失值用均值替换总是最佳方案吗？如何更好地保留“数据缺失”这一事实本身所包含的物理信息？

**解答**：
* 均值填补破坏了特征原有的分布方差，且隐式假设数据是“完全随机缺失（MCAR）”的。
* **进阶方案**：
  1. **指示变量标记（Indicator Column）**：除了用均值填补原特征外，额外增加一列布尔特征 `is_missing`，缺失填 1，否则填 0。这让模型能够自主学习“某项特征不填（如没有泳池面积）本身代表的额外含义”；
  2. **基于上下文的填补（KNN / 回归插补）**：利用同街区、同房型房屋的相似邻居特征进行加权插补，其精度远高于全局粗暴均值。

---

### 📌 练习 3：网络容量与正则化调优
> **问题**：尝试在 `get_net()` 中引入双隐藏层 MLP，配合 Dropout（$0.2$）和权重衰减（$10^{-4}$），观察 $K$ 折交叉验证分数相比单层线性模型的改善。

**实测经验结论**：
* 在该数据集上，经过充分特征工程（展开为 331 维）后，单层线性模型已经表现不俗（Log-RMSE 约为 $0.16$）；
* 引入带有 Dropout 的多层感知机（$331 \to 128 \to 64 \to 1$），能够捕捉不同特征间的交叉非线性组合效应（例如“优质学区”与“房龄极新”的联合增值非线性），能将 5 折验证集分数推进至 **$0.13 \sim 0.14$**，在 Kaggle 排名中取得实质性飞跃。
