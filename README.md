# 深度学习系统知识库（Deep Learning Knowledge Vault）

> **“格物致知，知行合一”** —— 本知识库基于经典教材《动手学深度学习》（*Dive into Deep Learning*, D2L PyTorch 体系）与前沿学术论文研读双轨构建。  
> 秉承**数学严谨性、底层工程透明度与前沿循证洞见**的融合原则，拒绝口语化冗余与机械拼凑，专注于打造一套兼具学术深度与实战价值的系统性知识资产。

## 🌟 知识库核心特色

1. **理论与工程双轨闭环**：
   * **从零开始实现（From Scratch）**：剥离框架高阶魔法，基于底层张量操作、自动微分与矩阵乘法亲手搭建网络核心算子（前向传播、自定义激活、反向传播链式求导、数值稳定性控制）；
   * **工业级简洁实现（Concise Implementation）**：利用 PyTorch 现代高阶 API（`torch.nn`, `torch.optim`, `DataLoader`）实现声明式建模，沉淀工业级最佳实践。
2. **全习题形式化数学推导**：
   * 全面覆盖教材各章节的所有课后思考题与探究题，提供严密的公式推导（如 Hessian 矩阵半正定性、Novikoff 收敛定理、Xavier/Kaiming 方差保持推导、贝叶斯 MAP 正则等价性证明等）与系统级排障对策。
3. **教材体系与学术前沿双向打通**：
   * 设立独立的【论文精读】板块，将课本理论延伸至 Nature/NeurIPS 顶刊顶会的前沿实证与批判性思考，形成从“基础原理”到“真实世界落地”的完整闭环。
4. **原生 Obsidian 离线知识网络与 GitHub 双重兼容**：
   * 所有架构图、数据流图与可视化曲线均为本地离线矢量化存储，杜绝图床失效；
   * 全局链接全面适配标准 Markdown 与 GitHub 网页端点击跳转，无论是本地 Obsidian 还是 GitHub 在线浏览均可秒级无缝穿透。
